# YouTube 유래 수집값 29일 보관 정리

- 날짜: 2026-11-11
- 누가: codex (AI 도구: Codex)
- 관련: docs/plan.md 5단계 / docs/spec.md R19·Areas of concern 6 / 커밋 없음(지시서에서 금지)

## 한 것

- 매일 수집 시작 전에 29일 이상 지난 자동 수집 후보의 영상 제목·언급 메모·signals.videos·signals.mentions·내부 점수를 정리한다. 직접 추가 후보와 이름·분류·상태·초안·네이버 값은 보존한다.
- 1000행씩 ID 순서로 조회하며, 변경할 값이 있는 행만 update한다. 조회·update 오류는 지정한 한국어 오류로 전달해 기존 pipeline_runs 실패 기록 경로로 보낸다.
- 승인한 초안의 foods.videos는 항상 0으로 저장하고, AI 초안 프롬프트에서 영상 언급 수를 빼고 YouTube 수치 금지 문구를 추가했다.
- R19·계획 5단계와 운영 안내를 갱신했다. 실제 외부 API는 호출하지 않았다.
