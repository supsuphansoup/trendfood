# 단일 대표 배치 복원과 크림·그린 색상 체계

- 날짜: 2026-11-17
- 누가: Codex
- 관련: docs/spec.md R1·R2 / docs/design.md 0장

## 한 것
- 사용자가 직전 배치를 선호한다고 밝혀 단일 대표 패널과 PC 2열·모바일 1열 목록, PC에서 넓어지는 세 번째 카드를 복원했다. 가로 카테고리와 필터 접기는 유지했다.
- 회색·검정 중심 면을 크림 바탕·살구 대표 면·짙은 그린 버튼·코랄 강조·세이지 보조 면으로 바꿨다. 첨부 로고 오렌지는 보존했다.
- 모바일에서도 카드 설명과 재료 담기 문구를 표시한다. 기존 출처·생성 예시 고지·추천 날짜·검색·찜·구매 동작을 유지했다. 유료 API나 이미지 생성 호출은 하지 않았다.

## 바뀐 파일
- `web/src/app/theme.css` — 공유 색상 토큰과 대표 제목 크기.
- `web/src/components/home/home-feed.tsx` — 단일 분할 대표 패널·반응형 목록 복원, 세이지 검색창.
- `web/src/components/home/food-card.tsx` — 넓은 설명 카드와 전체 문구 복원.
- `web/e2e/mvp.spec.ts` — 단일 대표·새 색상·PC 2열·모바일 1열·넓은 세 번째 카드 회귀 검사.
- `web/content-e2e/content.spec.ts` — 실제 데이터의 새 배치·팔레트·모바일 설명 검사.
- `docs/design.md`, `docs/spec.md` — 최신 요청에 맞춘 기준.
- 이 작업 기록.
