# 대표 사진 클릭으로 음식 상세 이동

- 날짜: 2026-11-19
- 누가: Codex
- 관련: docs/spec.md R1·R4, docs/design.md 0장

## 한 것
- 실제 서비스의 메인 사진 70개를 확인했다. 목록 69개는 상세 링크가 있었지만 맨 위 대표 사진에는 링크가 없었고, 실제 클릭 후에도 홈에 머무는 문제를 재현했다.
- 대표 사진 전체를 해당 음식의 상세 링크로 감쌌다. 기존 레이아웃·이미지·사진 정보 표시 방식은 유지했다.
- 대표 사진 가장자리 클릭·키보드 Enter 진입을 회귀 검사에 추가했다. 전체 목록 사진의 좌·중·우 지점이 음식명과 같은 상세 링크를 받는지 검사한다.
- 기존 카드 찜 버튼은 상세 이동 없이 독립 동작하는 검사를 유지했다.
