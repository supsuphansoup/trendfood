# 넓은 오렌지 면을 제거하고 음식명·사진으로 강조

- 날짜: 2026-11-18
- 누가: Codex
- 관련: docs/spec.md R1·R2 / docs/plan.md 공개 화면

## 한 것
- 사용자가 오렌지 대표 면을 거절해 디자인 원칙과 실제 음식 사이트를 다시 검토했다. `frontend-design` 스킬의 계획→검토→구현→캡처 비평 순서를 따랐다.
- [McGill 시각 위계](https://www.mcgill.ca/web-services/resources/toolkits/digital-design-toolkit/design-principles/visual-hierarchy), [Eater 개편 설명](https://www.eater.com/editor-newsletter/883816/eater-has-a-new-look)을 읽고 [Eater](https://www.eater.com/)·[The Infatuation](https://www.theinfatuation.com/)·[Bon Appétit](https://www.bonappetit.com/)의 실제 화면을 새로 캡처해 비교했다. 참고 캡처는 로컬 `web/data/ui-color-study/`에 보존한다.
- 오렌지 배너·이중 사진 프레임을 제거했다. 흰 바탕에서 큰 토마토 레드 음식명과 넓은 사진, 주 버튼·선택 상태의 일관된 레드로 강조한다.
- PC 음식명 72px·태블릿 48px·모바일 40px, 설명 18px·안내 14px. 선호 PC 설명/사진 분할과 모바일 사진→설명, 목록 배치를 보존했다. 출처·사진 안내·추천 근거·탐색·구매 기능은 유지했다.

## 바뀐 파일
- `web/src/app/theme.css` — 흰 대표 면·레드 역할·반응형 제목·사진 모서리 토큰.
- `web/src/components/home/home-feed.tsx` — 색 배너·프레임 제거, 사진·제목 비율과 행동 대비.
- `web/e2e/mvp.spec.ts` — 대표 색·크기·프레임 제거·안내 위치·접근성 회귀 검사.
- `web/e2e/admin.spec.ts` — 공통 주 버튼 테마 검사 갱신.
- `web/content-e2e/content.spec.ts` — 실제 콘텐츠 제목·배경과 캡처 검사.
- `docs/design.md` — 연구 근거·색·타입·배치·초안 검토.
- 이 작업 기록.

- E2E와 실제 콘텐츠 검사에 정적 빌드 포함, 접근성·검색·찜·필터·재료 담기 회귀 검사 통과.
- `node data/ui-photo-feed-check.mjs http://localhost:61809` → 320·390·768·1280px 모두 HTTP 200, 카드 29개, 사진·검색·필터 통과, 가로 넘침 없음, 주 버튼 첫 화면 노출, `LOCAL_EXIT=0`.
- 직접 열어 본 캡처: `web/test-results/hierarchy-home-{mobile,desktop}.png`, `web/test-results/content/hierarchy-home-{mobile,desktop}.png`, `web/test-results/content/feed-{mobile,desktop}.png`, `web/data/ui-live-hierarchy/home-{narrow,tablet}.png`.
- 캡처 비평: 큰 레드 음식명과 사진이 흰 면에서 분리되고 오렌지 배경의 색 경쟁이 없어졌다. 모바일 음식명·설명·버튼과 태블릿 줄바꿈, 기존 목록의 설명·행동 구분을 확인했다. 원본 사진 자체·생성 여부는 바꾸지 않았다. 로컬 검사 도구와 캡처는 배포·커밋 대상이 아니다.
