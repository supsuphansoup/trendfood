## 한 것

- 기존 자동 연결은 재료 일치 위주여서 초콜릿 70g에 5kg 상품, 스프레드 400g에 용량 미확인 상품이 연결된 문제를 확인했다.
- 질량·부피·개수를 구분하고 상품 단위 용량×수량으로 비교한다. 필요량 미달·지나친 총량·불명확한 옵션은 제외하며 같은 재료도 음식별 필요량에 따라 포장을 나눠 대조한다.

- 이전 자동 실행 보고서 `43238158187`에서 유래한 기존 링크 6개만 공개 검색 근거로 교체했다. 조리법·날짜와 다른 수동 링크는 보존했다.
