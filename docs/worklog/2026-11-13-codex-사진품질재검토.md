# 참고 사진의 메뉴 불일치·구도 재검토

- 날짜: 2026-11-13
- 누가: codex (AI 도구: Codex)
- 관련: 팀장 요청 — 사진들이 너무 이상함

## 한 것

- 로컬에 저장된 참고 사진 13개를 연락 시트로 직접 확인했다. 메뉴·주요 재료가 다르거나 책상·매대가 두드러진 사진 8개를 공개 콘텐츠에서 준비 중으로 변경했다. 기존 30개 음식 중 사진 5개를 유지하고 25개는 준비 중이다.
- 말차 라떼(아이스·호지차 두 잔), 크로플(오레오 크림), 새우 로제 떡볶이(새우 확인 불가), 새우 크림 리조또(레몬·차이브 리조또), 과일 탕후루(청포도와 다른 과일), 달고나 커피(책상·컴퓨터·약병), 소금빵(매대·가격표), 에어프라이어 계란빵(길거리 철판)을 제외했다.
- 등록부에 `rejectedReason`을 남겨 본문·히어로 재등록을 검증 단계에서 거절한다. 원본 사진 파일·출처·라이선스는 보존하며 자동 검색의 기존 사용 출처 제외 기준으로 같은 사진의 자동 재사용도 막는다.
- 자동 판별에 조리 단계와 전체 사진·3:2 중앙 크롭을 함께 제공한다. 기존 메뉴 일치에 더해 레시피 재료·토핑·음료 형태 일치와 음식 중심의 구도 적합성도 모두 통과해야 한다. 새 판별 항목이 누락된 이전 형식 응답은 보류한다.

## 정한 것·남은 것

- 좋은 사진을 확보하지 못한 음식은 어색한 유사 사진으로 채우지 않고 준비 중으로 둔다. 사진은 생성하지 않았다.
- 새 Commons 후보를 검색했으나 이 실행 환경의 외부 네트워크 제한으로 공식 API 요청이 `EACCES`로 실패했다. 새 사진의 실제 이미지·라이선스 메타데이터를 검증해 교체하는 작업과 실제 AI 자동 판별은 미검증이다.
- 현재 실행 환경은 `.git` 쓰기를 허용하지 않아 커밋·push를 수행하지 않았다. 변경은 로컬 작업 폴더에 있으며 공개 사이트 배포는 미반영이다. 기존 미추적 `.claude/`는 건드리지 않았다.
- AI 판별 항목을 늘려도 실제 정확도나 미적 품질이 보장되는 것은 아니다. 이번 검사는 통과·보류 처리와 실제 로컬 화면을 확인한다.
