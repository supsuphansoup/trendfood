# 사진과 음식 탐색을 강조한 공개 화면 개편

- 날짜: 2026-11-16
- 누가: codex (AI 도구: Codex)
- 관련: docs/spec.md R1·R2·R4 / docs/design.md 0장

## 한 것
- 최근 UI 경향에 맞고 눈에 들어오는 화면을 요청받아, 기존 색상과 Pretendard를 유지하면서 홈·음식 상세의 배치를 개편했다.
- 홈은 흰 헤더와 검색 실행 버튼, 빨강 설명 면과 사진을 나눈 대표 음식 패널, PC 두 열 목록으로 구성했다. 모바일은 사진과 카드를 한 열로 배치한다.
- 큐레이션 카드에는 순위 숫자 대신 카테고리·확인된 유행 연도를 표시한다. 상세는 사진과 설명을 분리하고 조리법·재료 구역으로 이동하는 링크를 추가했다.
- 기능·접근성 검사와 실제 콘텐츠 30개 검사를 실행하고 모바일·PC 스크린샷을 열어 확인했다. 검사 중 발견한 소개 영역의 접근성 랜드마크 누락과 대표 사진의 흐림 배경 넘침을 수정한 뒤 재검사했다.

## 바뀐 파일
- `web/src/components/home/home-feed.tsx` — 헤더·대표 음식 패널·검색 버튼·목록 배치.
- `web/src/components/home/food-card.tsx` — 사진 중심 카드·연도 표시·광고 앞 가로 카드.
- `web/src/app/food/[slug]/page.tsx` — 사진과 설명 분리·조리법 및 재료 이동 링크.
- `web/src/app/theme.css` — 대표 영역 모서리·제목 크기 토큰 추가.
- `web/e2e/mvp.spec.ts` — 검색 실행·44px 버튼·목록 반응형 배치·상세 이동 검사 추가.
- `web/content-e2e/content.spec.ts` — 실제 콘텐츠의 반응형 목록·사진 표시·검색 실행 검사 추가.
- `docs/design.md`, `docs/spec.md` — 개편한 배치와 기준 반영.
- `docs/worklog/2026-11-16-codex-음식탐색-화면개편.md` — 이 작업 기록.

## 정한 것·남은 것
- 요청에 맞춰 빨강 대표 패널·PC 두 열 목록·광고 앞 세 번째 가로 카드를 적용했다. 광고 위치·횟수는 유지했다.
- 새 패키지, 이미지 생성·교체, 음식·상품 데이터 수정은 없다. 프로젝트 OpenAI API를 호출하지 않았다.
- 사진 출처·라이선스·생성 안내와 제휴 고지는 유지했다. 쿠팡 품절 상품 교체·브라우저 연결 문제는 앞선 요청대로 보류다.
- 원격 배포 결과는 push 후 GitHub Actions에서 확인한다.
