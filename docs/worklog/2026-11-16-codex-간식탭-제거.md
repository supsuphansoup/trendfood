# 카테고리에서 간식 탭 제거

- 날짜: 2026-11-16
- 누가: Codex
- 관련: docs/spec.md R2 / docs/design.md 0장

## 한 것
- 디저트와 겹치는 간식 탭을 PC·모바일 카테고리에서 제외했다.
- 간식 음식의 원래 분류 데이터는 유지하며 전체 목록·검색에서 계속 제공한다.
- 이전 `?cat=간식` 주소는 전체 목록으로 열리고 제거된 필터를 주소에서 지운다.

- `web/e2e/mvp.spec.ts` — 간식 탭 부재·이전 주소의 전체 전환·기존 음식 유지 검증.
- `web/content-e2e/content.spec.ts` — 실제 콘텐츠의 간식 탭 부재·이전 주소·음식 검색 검증 및 화면 기록.
- `docs/spec.md`, `docs/design.md` — 공개 카테고리 기준 갱신.
