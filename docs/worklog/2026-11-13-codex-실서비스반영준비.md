# 실서비스 반영 경로 확인과 전달 자료 준비

- 날짜: 2026-11-13
- 누가: Codex
- 관련: docs/spec.md R14·R18 / docs/live-publish.md

## 한 것
- 사용자의 실제 서비스 반영 요청에 따라 기존 GitHub main → Actions → Cloudflare Pages 경로와 사진 예약 실행 설정을 확인했다.
- GitHub API·원격 main 조회·브라우저 연결을 실제 시도했으나 현재 환경의 연결 제한으로 원격 변경을 진행하지 못했다.
- 일반 PC 터미널에서 검증된 파일만 반영할 수 있도록 배포·설정·사진 실행·서비스 확인 절차를 작성하고 이미지 관련 변경 파일의 SHA256 목록과 ZIP을 준비했다.

## 바뀐 파일
- `docs/live-publish.md` — 기존 서비스 반영 절차, 실패 시 중단, 운영 검증 기준.
- `docs/worklog/2026-11-13-codex-실서비스반영준비.md` — 이번 작업 기록.
- `web/data/live-release/manifest.json`·`release.zip` — 전달용 산출물, Git 무시 대상.
- 기존 코드와 이미지 파일은 이번 작업에서 추가 수정하지 않았다.

## 검사 결과
- `gh api repos/supsuphansoup/trendfood`: 종료 코드 1, `connectex: An attempt was made to access a socket in a way forbidden by its access permissions.`
- `git -c credential.interactive=never ls-remote origin refs/heads/main`: 종료 코드 1, `Could not connect to server`.
- 브라우저: `The browser access host is unavailable`, 네이티브 연결도 사용할 수 없음.
- 웹 도구의 서비스·워크플로 조회도 실패했다. 현재 배포 버전과 실행 상태는 확인하지 못했다.
- 문서만 추가했으므로 경로·파일 목록·ZIP 무결성을 검사했다. 이전 코드 변경의 최근 검사는 lint 종료 0, typecheck 종료 0, unit `129 passed`, e2e `122 passed (25.6s)`, 공개 콘텐츠 `8 passed (11.4s)`다. 이번에 이 검사들을 다시 실행한 것으로 보고하지 않는다.
- 전달 파일 62개와 ZIP 항목 63개(내부 manifest 포함)를 확인했고 생성 이미지 26개를 포함한다. 압축 내부의 모든 전달 파일을 SHA256으로 대조했다. 비밀값·개인 설정·Git 메타데이터·빌드 결과는 포함하지 않았다.
- 최초 전달물 준비 명령은 이 환경의 `Get-FileHash` 미제공과 `src/data`까지 제외한 경로 조건 때문에 실패했다. .NET SHA256과 정확한 제외 경로로 수정한 뒤 재실행해 종료 코드 0을 확인했다. 배포 안내의 해시 검사도 같은 .NET API를 사용한다.
- `git diff --check` 통과, 전달 산출물 두 개가 기존 Git 무시 규칙에 포함됨을 확인했다.

## 정한 것·남은 것
- 호스팅·AI 모델·처리량을 변경하지 않았다. 배포 안내는 기존 공개 JSON·사진 자동 검색·검증 후 자동 반영 설정을 유지하도록 한다.
- 실제 커밋·push·저장소 변수 변경·사진 예약 실행·서비스 배포는 하지 못했다. 권한이 허용되는 실행 환경에서 안내 절차를 실행하고 실제 서비스 결과를 확인해야 한다.
- `.claude`와 비밀값 파일은 전달 대상에서 제외한다. 배포에 필요한 비밀값을 문서나 전달 파일에 복사하지 않는다.
