## 정한 것·남은 것
- 사용자 요청은 공개 구역 제거로 해석했다. 기존 사서 맛보기 저장값·관리자 편집은 보존했다.
- 음식 데이터·사진·자동 수집·추가 API 호출은 변경하지 않았다.
- 시작 및 push 전 원격 기준: `ef5a63d78257d8d707d95cd88b088dec0562e3c3`. `git fetch origin main` 후 새 원격 커밋·변경 파일 없음. 가져올 팀원 변경과 충돌 없음.
- 원래 작업 폴더의 미커밋 변경은 건드리지 않고 기존의 깨끗한 별도 worktree에서 작업했다.
- 커밋 후 `git pull --rebase origin main`으로 통합 상태를 확인하고 공통 pre-push 훅을 통과한 결과만 push한다. 원격이 바뀌면 통합·검사를 반복한다.
