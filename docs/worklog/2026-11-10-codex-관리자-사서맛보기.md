# 관리자 사서 맛보기 편집과 빈 공개 구역 숨김

- 날짜: 2026-11-10
- 누가: codex (AI 도구: Codex)
- 관련: docs/plan.md 2단계 / docs/spec.md R16 / 커밋 없음(지시서에서 금지)

## 한 것
- 기존 사진·재료·조리법 편집 아래에 사서 맛보기 구역을 더했다. 목록의 기존 값으로 즉시 초기화하고 파는 곳·설명 추가/삭제/순서 변경과 구역별 저장을 지원한다.
- 공백·빈 칸·길이·중복·6개 제한을 순수 함수로 검증한다. 0개는 정상이며 저장 요청은 `convenience` 열만 포함하고 성공 뒤 목록을 다시 불러온다.
- 사서 맛보기 값이 없으면 공개 상세 구역을 숨긴다. 계란 파 라면 예시만 빈 배열로 바꾸고 SQL을 재생성했다.
- 단위·관리자 E2E·공개 상세 E2E를 추가하고 spec·plan·온보딩의 지정된 줄을 갱신했다.
