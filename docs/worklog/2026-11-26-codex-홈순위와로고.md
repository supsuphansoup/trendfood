# 홈 1~3위와 브랜드 로고 정렬

- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R1, `docs/design.md` 홈 전체 화면·브랜드

## 한 것

- 홈 첫 화면 하단에 확인된 유행 시기순으로 1~3위와 음식 이름을 동시에 표시했다. 순위를 누르면 그 음식의 사진·이름·상세 링크로 전환된다. 자동 넘김·좌우 이동도 선택 표시와 연동된다.
- 로고를 원본 3:1 비율로 표시하고, PNG의 투명 여백을 감안해 홈 제목과 왼쪽 선을 맞췄다. PC에서는 로고와 오른쪽 바로가기 사이에 검색창을 가운데 정렬했다.

## 바뀐 파일

- `web/src/components/home/home-feature.tsx` 순위 선택과 캐러셀 연동
- `web/src/components/home/home-feed.tsx` 홈 헤더 배치
- `web/src/components/site-logo.tsx` 로고 크기와 원본 비율
- `web/src/app/globals.css` 순위 영역과 짧은 화면의 여백
- `web/content-e2e/content.spec.ts`, `web/e2e/mvp.spec.ts` 순위 선택·순환과 로고 표시 검사
