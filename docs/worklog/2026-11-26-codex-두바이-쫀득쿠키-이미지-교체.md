# 두바이 쫀득쿠키 이미지 교체

- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R4와 `docs/automation.md`의 재검토 사진 규칙

## 한 것

- 실제 쿠키의 얇은 코코아 마시멜로 겉피와 촘촘한 피스타치오·카다이프 단면을 참고해 통쿠키 한 개와 자른 두 조각을 접시에 담은 AI 예시를 만들었다.
- Real rism의 Wikimedia Commons 원본을 연결하고 변환본의 CC BY-SA 4.0 이용 조건을 표시했다. [참고 원본](https://commons.wikimedia.org/wiki/File:Korean_Dubai_Jjondeuk_Cookie.jpg)

## 바뀐 파일

- `web/src/assets/generated/photo-ai-dubai-chewy-cookie-cut-20261126.webp`에 1200 × 800 이미지를 추가하고 `web/src/lib/generated-photos.ts`에 등록했다.
- `web/src/data/content/generated-images.json`에 생성 도구·프롬프트·원본 출처와 변환 내역을 기록했다.
- `web/src/data/content/foods.json`에서 두바이 쫀득쿠키 이미지와 대체 텍스트를 바꿨다.
- `web/content-e2e/content.spec.ts`에서 검색 카드와 상세가 같은 새 이미지를 사용하는지 확인하고 상세 캡처를 추가했다.
