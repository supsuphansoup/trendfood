- 날짜: 2026-11-20
- 누가: Codex
- 관련: 사용자 요청 — 기존 음식의 생성 사진도 실제 음식 사진을 참고해 다시 제작

## 한 것
- 공개 중인 기존 생성 사진 21장을 레시피 원문·제조사·제품 보도 사진과 직접 대조해 다시 제작했다. 앞서 교체한 새 음식 3장과 기존 실사는 유지했다.
- 버터떡의 조개 틀, 피자설기의 백설기 단면, 로제떡볶이의 납작한 떡, 참치김밥의 단순한 속재료 등 음식별 특징과 현재 레시피 재료를 반영했다. 피자설기의 첫 결과는 밥알처럼 보여 다시 제작한 결과를 채택했다.
- 대화의 내장 `image_gen`으로 제작했다. 사용자 OpenAI API 키를 이용한 추가 유료 호출이나 예약 생성 연결은 하지 않았다.
- 새 파일을 별도 이름으로 연결하고 이전 이미지·프롬프트를 보존했다. 참고 사진 원본은 게시하지 않으며 생성 예시 안내를 유지했다.

## 바뀐 파일
- `web/src/assets/generated/*-ref-v2.webp` — 참고 사진을 반영한 1200×800 WebP 21장
- `web/src/lib/generated-photos.ts` — 기존 이미지 키를 새 파일로 연결
- `web/src/data/content/generated-images.json` — 새 생성일·프롬프트·예시 안내
- `web/src/data/content/generated-reference-revisions.json` — 실제 참고 출처·이전 프롬프트·이전 및 새 파일 경로
- `web/scripts/content.test.ts` — 실제 연결 파일 검사 및 출처·원본 보존 회귀 검사
