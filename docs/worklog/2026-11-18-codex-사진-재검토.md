# 음식 사진 재검토와 교체

- 날짜: 2026-11-18
- 누가: Codex
- 관련: 사용자 요청 / `docs/spec.md` 사진·R14

## 한 것

- 공개 음식 70개의 카드 구도를 비교했다. 흐림·손과 반찬 용기·과한 배경·음식이 잘 드러나지 않는 구도를 우선 검토했다.
- 계란국·크림파스타·감자조림·어묵볶음·제육볶음·국물우동·오므라이스·우베 라떼·잔치국수 9개를 다른 실사로 교체했다. Commons 공식 API에서 원본·작가·이용 조건을 다시 조회하고 후보 원본과 카드 구도를 열어 대조했다.
- 오이무침은 허용 조건 안에서 더 적합한 동일 메뉴 실사를 확보하지 못해 기존 사진에서 손과 용기 테두리가 보이지 않는 음식 영역으로 잘랐다. 다른 음식 사진이나 미나리 중심의 무침으로 대체하지 않았다.
- 사진 10개에 새 키를 부여하고 기존 키에는 제외 이유를 보존했다. 원본 파일·출처·라이선스와 생성 예시 기록은 보존했다. 유료 OpenAI API·이미지 생성은 호출하지 않았다.
- 원본 크기에 대한 자르기 비율을 등록부에 보존하고 `photos:sync`가 같은 구도를 적용하게 했다. 음식 설명·재료·조리법·추천 순서는 변경하지 않았다.

## 정한 것·남은 것

- 새 후보가 기존보다 적합하지 않았던 말차 라떼·토마토파스타·어묵탕은 기존 사진을 보존했다. 간장계란밥도 원본을 다시 열어 달걀 프라이임을 확인했다.
- 사진은 직접 조리한 결과가 아닌 참고 실사다. 레시피와 일부 토핑·채소·담음새 차이를 안내한다.
- `photos:sync` 전체 원본 재다운로드는 실행하지 않았다. 해당 명령이 사용하는 동일 렌더 함수의 반복 결과와 잘린 영역의 픽셀을 단위 검사했다.
- 공개 배포 이후 실제 서비스의 새 이미지 주소·로딩·출처를 별도로 확인한다.
