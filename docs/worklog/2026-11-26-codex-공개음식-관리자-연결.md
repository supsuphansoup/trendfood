# 공개 음식 전체를 게시 관리에 연결

- 날짜: 2026-11-26
- 누가: Codex
- 관련: `docs/spec.md` R10–R16 · `docs/plan.md` 관리자 편집 보강

## 한 것

- 공개 JSON과 같은 기준 커밋의 음식 전체를 관리자 로그인 후 불러온다. 이름·주소 검색, 기본 정보·글·사진·영상·재료·조리법·링크 편집, 순서 변경, 숨김·복구, 초안 전환을 연결했다.
- 편집한 필드와 내림 이력을 Supabase에 저장한다. 사이트 반영 요청 전에는 공개 확정본이 바뀌지 않는다. 저장 버전을 비교해 동시 편집 시 앞선 저장을 보존한다.
- 정적 빌드 시 공개 확정본을 최신 JSON에 적용한다. 숨김·초안은 공개 홈·상세·사이트맵에서 제외한다. 사진과 페이지는 같은 빌드 시점의 데이터를 사용한다.

## 바뀐 파일

- `web/src/components/admin/`, `web/src/app/admin/page.tsx` — 공개 목록 및 기존 편집·재료 링크 화면 연결.
- `web/src/data/content-edits.ts`, `web/src/data/content.ts`, `web/src/data/catalog-schema.ts`, `web/src/data/youtube.ts`, `web/src/data/admin-food-edit.ts` — 수정 필드 검증과 공개 레코드 변환.
- `web/supabase/migrations/0005_content_edits.sql` — 관리자 저장본, 공개 확정본 조회, 내림 기록과 RLS.
- `web/src/lib/catalog.ts`, `web/src/lib/supabase-config.ts`, `web/scripts/fetch-photos.ts`, `.github/workflows/deploy.yml` — 공개 확정본과 사진을 정적 빌드에 적용.
- `web/scripts/content-edits.test.ts`, `web/content-e2e/admin-content.spec.ts`, `web/content-e2e/admin-api.ts`, `web/playwright.content.config.ts`, `.github/workflows/ci.yml` — 단위·공개 모드 관리자 화면 및 빌드 회귀 검사.
- `docs/automation.md` — 운영 DB 적용과 기능 활성화 절차.

## 정한 것·남은 것

- 변경 필드만 저장하고, 순서를 직접 바꾼 경우 해당 음식의 상대 순서만 저장한다. 새 자동 수집 음식은 원본에서 정한 위치를 사용한다.
- 운영 Supabase에 `0005_content_edits.sql`을 적용한 뒤 `TF_CONTENT_ADMIN=1`로 배포한다. 운영 프로젝트 SQL Editor 접속은 현재 세션에서 확인되지 않았다.
