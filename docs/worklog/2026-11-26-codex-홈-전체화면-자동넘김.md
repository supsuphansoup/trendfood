# 홈 전체 화면과 자동 넘김 적용

- 날짜: 2026-11-26
- 누가: Codex
- 관련: `docs/spec.md` R1
- 원격 기준: `c145c28550852eab39eff5bac0f6fae2819b223e`. 디저트 분류를 통합한 팀원 커밋을 반영한 복제본을 사용했다. 작업 중 새 원격 커밋과 충돌은 없었다.

## 한 것

- 사용자가 고른 B안을 홈에 적용했다. 헤더 아래 전체 폭 사진 위에 서비스 안내, 음식명과 유행 배경, 상세·영상 버튼을 둔다.
- 별도의 이웃 추천 카드 없이 사진과 설명을 함께 좌우로 이동한다. 모바일 스와이프, PC 드래그, 버튼과 키보드 방향키를 지원한다.
- 8초마다 추천 세 장을 순환한다. 일시정지와 재개 버튼을 제공한다. 마우스 호버, 키보드 포커스, 페이지 숨김과 동작 줄이기 설정을 반영했다. [W3C 캐러셀 지침](https://www.w3.org/WAI/ARIA/apg/patterns/carousel/)
- 로컬에서 검토한 `vviralfood` 이름과 첨부 로고도 함께 적용했다. 실제 유행 추천 순서, 출처와 목록 동작을 사용한다.

## 바뀐 파일

- `web/src/components/home/home-feature.tsx`, `web/src/components/home/home-feed.tsx`: 전체 화면 추천과 자동·수동 전환.
- `web/src/components/food-image.tsx`, `web/src/app/globals.css`, `web/src/app/theme.css`: 홈 사진 채우기와 화면 크기별 글자·버튼·배경.
- `web/e2e/mvp.spec.ts`, `web/content-e2e/content.spec.ts`: PC·모바일 표시와 이동, 자동 넘김 시각, 정지 조건, 영상과 상세 연결 검사.
- `.gitattributes`: Windows에서 훅 테스트가 복사하는 원본 스크립트의 줄 끝을 LF로 유지.
- `docs/design.md`: 확정안과 자동 넘김 기준.
