# 차분한 색상과 사진 중심의 공개 UI 개편

- 날짜: 2026-11-17
- 누가: Codex
- 관련: docs/plan.md 검증 / docs/spec.md R1·R2·R4

## 한 것
- 밝은 회색 바탕·잉크색 본문·흰색 카드를 사용하고 오렌지는 주 버튼·검색·분류 배지에 집중했다.
- 대표 음식의 큰 빨간 면을 옅은 세이지색으로 바꾸고, 제목 크기·설명·버튼의 위계를 정리했다. 사진은 PC 좌우 배치·모바일 위쪽 배치를 유지했다.
- 목록에 흰색 면·경계·안쪽 여백을 더해 음식 사진과 설명이 배경에서 구분되게 했다.
- 검색·필터·찜·광고 위치·재료 구매·실사 출처·생성 이미지 안내를 유지했다. 이미지 생성·유료 수집 API는 호출하지 않았다.

## 바뀐 파일
- `web/src/app/theme.css` — 색상·제목 크기·대표 면 토큰
- `web/src/components/home/home-feed.tsx` — 소개 문구·대표 패널·검색 버튼·목록 간격
- `web/src/components/home/food-card.tsx` — 카드 면·분류 배지·버튼 위계
- `web/e2e/mvp.spec.ts` — 새 테마와 반응형 사진 배치·CTA 이동·카드 구분 검사
- `docs/design.md` — 최신 팔레트와 화면 기준
- `docs/worklog/2026-11-17-codex-차분한-포인트-UI.md` — 이번 작업 기록

## 정한 것·남은 것
- 사용자의 ‘너무 튀지 않으면서 눈에 들어오는’ 요청을 차분한 바탕과 작은 오렌지 포인트로 해석했다. 새 패키지는 추가하지 않았다.
- 기존 작업 폴더의 필터 접기 관련 미커밋 변경은 보존했다. 이번 UI 변경만 별도 작업 폴더로 분리해 커밋한다.
- 운영 반영은 main에 push한 뒤 자동 배포 결과와 운영 주소의 실제 화면을 확인한다.
