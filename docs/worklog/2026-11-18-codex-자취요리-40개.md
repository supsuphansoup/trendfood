# 간편한 자취 요리 40개와 실사 사진 추가

- 날짜: 2026-11-18
- 누가: Codex
- 관련: 사용자 요청 / `docs/spec.md` R1·R2·R4·R6·R14

## 한 것

- 기존 일상 레시피 8개에 40개를 더해 자취 요리 48개, 전체 음식 70개를 제공한다. 기존 30개 음식의 내용·순서와 추천 메타데이터는 그대로 보존했다.
- 김치볶음밥·간장계란밥·카레·국수·파스타·국·찌개·두부조림·계란말이·나물·전·토스트 등 익숙한 집밥을 골랐다. 예상 시간은 손질 포함 10~45분이며 밥·육수·삶은 달걀·시판 반죽 등 미리 필요한 준비는 재료와 안내에 명시했다.
- Maangchi, 새미네부엌 요리연구소, 오뚜기레시피, Barilla, Kewpie 원문에서 재료·분량·과정을 대조했다. 분량 환산과 시판 육수 등의 변경 사항, AI 요약과 참고 사진임을 각 상세에 적었다.
- Wikimedia Commons 공식 API의 허용 라이선스 실사 40장을 각각 연결했다. 사진을 열어 음식·구도를 확인했고, 유부초밥·국수·샌드위치 등 부적합 후보를 교체했다. 작가·원본·라이선스·SHA1·변환 안내를 보존했다. 국물우동 사진은 우동 그릇 부분을 잘랐다.
- 작가 메타데이터가 비어 있던 오이무침·감자조림은 공식 API의 원본 업로더 Valenzuela400와 파일 설명의 self CC BY-SA 4.0 표기를 대조해 출처를 보완했다.
- 확인하지 않은 상품 상세 주소·가격·인기 수치를 만들지 않았다. 신규 재료는 기존 쿠팡 일반 검색 연결을 이용한다. 유료 OpenAI API 호출과 이미지 생성은 하지 않았다.

## 바뀐 파일

- `web/src/data/content/foods.json` — 새 비유행 레시피 40개와 원문 출처 추가.
- `web/src/data/content/auto-photo-credits.json` — 작업 중 메뉴·구도를 대조해 선택한 실사 출처 40개 등록(`automatic: false`).
- `web/src/assets/curated/photo-everyday-*.webp` 40개 / `web/src/lib/curated-photos.ts` — 실사 파일과 번들 연결.
- `web/scripts/content.test.ts` — 자취 요리 수·분량·원문·실사·가짜 상품 주소 방지 회귀 검사.
- `web/content-e2e/content.spec.ts` — 신규 요리 검색·분량·일반 구매 검색·실사 표시, 상세 화면 캡처. 자동 적용 사진에만 자동 검수 안내를 검사하도록 구분.

## 팀원 변경 확인·통합

- 작업 시작 및 구현 후 `git fetch origin main` 기준: `7fe3148dc290629968a0d1a653cef77ef9fc669e`.
- 구현 후 `git log --oneline HEAD..origin/main` / `git diff --name-status HEAD...origin/main`: 새 원격 변경 없음.
- 원래 작업 폴더의 타인 미커밋 변경은 건드리지 않고 기존 깨끗한 worktree에서 진행했다.
- 검사 후 원격을 다시 비교해 같은 기준 커밋임을 확인하고 push한다. 가져올 팀원 커밋과 충돌은 없으며 위 검사는 최신 원격 위에서 수행했다. 공통 pre-push 훅도 우회하지 않는다.

## 정한 것·남은 것

- “40개 정도 추가”는 기존 8개에 신규 40개를 더하는 것으로 해석했다. 통계에 근거한 인기 순위를 새로 부여하지 않고 익숙한 일상 메뉴를 편집 선정했다.
- 복잡한 볶음우동 대신 간편한 콘치즈를 넣었다. 레시피는 직접 조리 시험을 한 결과가 아니라 원문 대조·분량 환산·간편 응용이다.
- 공개 반영은 커밋·push 이후 자동 배포 결과와 실제 페이지에서 별도 확인한다. 직접 조리 시험과 신규 재료의 일반 상품 상세 링크 발급은 이번 작업 범위에 포함하지 않았다.
