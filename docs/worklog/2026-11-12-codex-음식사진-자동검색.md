# 음식 사진 자동 검색·대조·적용

- 날짜: 2026-11-12
- 누가: Codex
- 관련: 팀장의 "사진도 알아서 찾아서 적용" 요청, `docs/automation.md`

## 한 것
- Commons 공식 API에서 정확한 메뉴 이름을 검색하고 CC0·퍼블릭 도메인·작가·출처·크기·별도 제한 여부를 코드로 확인한다. 실제 사진 바이트와 메뉴·파일 설명을 기존 선택 모델로 대조해 통과한 경우만 적용한다.
- 기존 사진과 조리법·확인 날짜는 유지한다. 새 사진의 작가·원문·이용 조건·확인 날짜·문서 ID·원본 SHA1을 보존하고 자동 대조·개별 미검수·WebP 변환 안내를 표시한다.
- 하루 3회 수집 작업 뒤 사진 준비 중 항목을 5개씩 순환 확인한다. 사진만 최대 20개 확인하는 수동 실행도 지원하며 음식·사진 파일·등록부·번들 목록을 함께 검사·커밋·배포한다.

## 바뀐 파일
- `web/scripts/photo-automation.ts`, `auto-photos.ts`, `photo-assets.ts`, 관련 테스트 — 공식 검색, 다운로드 제한, 이미지 대조, 보류·재실행, 파일 반영.
- `web/scripts/pipeline/llm.ts`, `llm.test.ts` — 기존 공급자·모델의 이미지 입력 지원. 원문·이미지 바이트를 로그에 남기지 않는다.
- `web/src/data/content/auto-photo-credits.json`, `photo-credits.ts`, `scripts/photos.ts` — 자동 사진 등록과 기존 수동 사진 동기화의 공통 번들 목록.
- `.github/workflows/pipeline.yml`, `web/package.json`, `docs/automation.md`, `AGENTS.md` — 예약 작업 연결·설정·중지·수동 실행 방법.

- `npm run lint`: 통과.

- `npm run test:unit`: 92개 통과, 실패 0개. 이용 조건·가짜 주소·다운로드 제한·실제 이미지 입력·불일치·합성·가림·동일 사진 재사용·보류·AI 한도·순환·키 누락 회귀 검사 포함.
- `npm run test:e2e`: 122개 통과, 실패 0개.

## 정한 것·남은 것
- 별도 승인 없이 사진도 적용하라는 요청으로 해석했다. 기본 실행당 5개·사진 후보 최대 3개 대조, 모델 신뢰 응답 0.95 이상을 적용 조건으로 정했다. 이 수치는 실제 정확도 보장이 아니다.
- 적합한 이용 조건의 동일 메뉴 사진이 없거나 판별이 불확실하면 준비 중을 유지한다. 생성 사진·플랫폼 썸네일·일반 웹 이미지 스크래핑은 사용하지 않는다.
- 기존 AI 공급자·모델을 유지한다. 저장소 변수 `PIPELINE_AUTO_PHOTOS=true`로 활성화했으며 `false`로 사진 자동화만 중지할 수 있다.
