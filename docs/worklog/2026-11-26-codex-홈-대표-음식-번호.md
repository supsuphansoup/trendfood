- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R1

## 한 것

- 홈 첫 화면의 대표 음식명 왼쪽에 강조색 숫자 1·2·3과 얇은 구분선을 넣었다. 사진을 넘기면 번호도 음식과 함께 이동한다.
- 공개 콘텐츠로 만든 정적 미리보기를 `http://127.0.0.1:3001/`에서 띄웠다. 검토 범위는 로컬이다.

- `web/src/components/home/home-feature.tsx`, `web/src/app/globals.css` — 제목 옆 번호와 스타일.
- `web/content-e2e/content.spec.ts` — 모바일·PC의 번호 위치, 같은 음식과의 연결, 3에서 1로 순환하는 동작을 확인한다.

## 정한 것·남은 것

- 번호는 대표 음식이 여러 장일 때 표시한다. 화면 낭독기는 기존 음식 이름·슬라이드 위치 안내를 사용한다.
- 작업 시작 때 `origin/main`은 `6dcec2af844dae61205e22269bebe09a91795e52`였고 가져올 팀원 변경과 충돌은 없었다. 로컬 미리보기이므로 커밋은 원격에 올리지 않았다.
