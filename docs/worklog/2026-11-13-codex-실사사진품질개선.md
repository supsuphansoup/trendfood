# 실사 상세 사진의 과한 확대 개선과 자동 구도 검사 보강

- 날짜: 2026-11-13
- 누가: Codex
- 관련: `docs/spec.md` 사진 표시 / `docs/design.md` 사진 구도 / `docs/automation.md` 사진 검사

## 한 것
- 사용자가 실사 품질을 지적해 운영 스크린샷과 원본을 다시 대조했다. 달고나 커피는 가로 상세에서 거품만 남고 달고나는 모양이 잘리는 문제가 있었다.
- 세로·정사각 실사의 홈 대표·상세 배너는 원본 비율을 보존하고 PC 오른쪽·모바일 중앙에 표시한다. 같은 사진의 흐린 장식 배경을 사용하며 이미지 대체 설명은 중복하지 않는다.
- 자동 판별에 전체·카드 외 PC·모바일 상세 구도를 추가하고 음식 식별뿐 아니라 조명·색·반사·진열 상태가 먹음직스러움을 해치는지도 확인하게 했다. 후보·일일 음식 개수·판별 호출 횟수·예약 시각은 보존했다.
- Commons 공식 API로 추가 커피·뜨거운 말차·뽑기 후보를 찾고 원본을 열었다. 기존 사진보다 확실히 나은 대체본을 확보하지 못해 사진 교체 실적으로 세지 않았다. 실사 9개·생성 예시 21개다.

## 바뀐 파일
- `web/src/components/food-image.tsx` — 실사 상세의 원본 비율과 장식 배경.
- `web/src/data/photo-presentation.ts` — 화면·검사에서 공유하는 상세 표시 방식.
- `web/scripts/photo-automation.ts` — PC·모바일 상세 검사 미리보기와 품질 지침.
- `web/scripts/photo-automation.test.ts` — 네 구도 전달 및 세로 사진 상하 보존·품질 부적합 보류 회귀 검사.
- `web/content-e2e/content.spec.ts` — 실제 모든 실사의 표시 방식·장식 이미지 접근성 제외 검사.
- `docs/automation.md`, `docs/design.md` — 표시·자동 검사 기준.
- 이 작업 기록.

## 정한 것·남은 것
- 3:2보다 세로로 긴 실사의 대형 배너 표시 방식을 바꾸는 것으로 해석했다. 새 원본 확보나 촬영 품질 개선까지 완료했다고 보고하지 않는다.
- 기존 촬영 품질·반사·진열 상태의 한계는 남아 있다. 더 좋은 정식 이용 가능 원본 확보가 필요하다. 유료 사진을 구매하거나 임의의 블로그 사진을 가져오지 않았다.
- 자동 검사 보강은 코드와 가짜 판별 응답으로 검증했다. 실제 AI의 미적 판별 정확도가 보장되거나 이번 변경으로 예약 실사 교체가 성공했다고 주장하지 않는다.
- 구현 커밋 `fd8e8c483af9338a3a5d125c637108325b570bdf`를 main에 반영했다. [운영 배포](https://github.com/supsuphansoup/trendfood/actions/runs/43442870478)는 성공했고 `https://e2f4cc41.trendfood.pages.dev`와 `https://trendfood.pages.dev`에서 확인했다.
- 실제 운영 Playwright 확인: 모바일·PC 각각 홈 카드 29개·이미지 로드 31개(장식 배경 포함), 실사 9개·생성 21개, 변경 실사 상세 5개·생성 상세 1개, 자체 리소스 실패 0개. 실사의 `object-fit`·모바일 중앙/PC 오른쪽 배치·출처·라이선스를 검사했다.
- 운영 스크린샷 `web/data/live-production-desktop.png`, `web/data/live-production-dalgona-coffee-desktop.png`를 열어 홈과 상세 반영을 확인했다. 홈과 상세가 같은 이미지 컴포넌트를 사용하는 점을 디자인 문서에도 명시했다.
- [GitHub CI](https://github.com/supsuphansoup/trendfood/actions/runs/43442870847)도 최종 성공했다. 표준 설정의 네 검사와 실제 콘텐츠 검사를 모두 통과했다.
