# 카테고리에 자취 요리 진입 추가

- 날짜: 2026-11-18
- 누가: Codex
- 관련: docs/spec.md R1·R2 / docs/plan.md 7단계

## 한 것
- 기존 유행 음식의 대표·기본 목록 순서는 보존하고 ‘전체’ 바로 옆에 ‘자취 요리’ 탭을 추가했다.
- 기존 일상 레시피 분류(유행 기록이 없는 레시피, 현재 8개)를 연결했다. 완제품·소개 전용 음식은 제외하며 새 음식 원고는 만들지 않았다.
- 기존 `collection=everyday` 주소를 재사용해 새로고침·뒤로가기·검색·상세 이동을 유지했다. 기존 일상 레시피 모음 버튼도 같은 동작을 사용한다.
- 진입 시 유행 연도·태그를 해제하고 유행 연도 선택은 숨겼다. 다른 카테고리로 이동하면 일상 모음을 해제한다. 일상 카드에는 순위 숫자를 표시하지 않는다.

## 바뀐 파일
- `web/src/components/home/home-feed.tsx` — 카테고리 탭·선택 표시·개수·주소·필터 처리
- `web/src/components/home/food-card.tsx` — 일상 목록의 순위 숨김
- `web/e2e/mvp.spec.ts` — 기본 순위 보존·키보드·주소·검색·복귀·소개 전용 음식 제외 검사 추가
- `web/content-e2e/content.spec.ts` — 실제 8개 분류·연도 해제·상세 이동·기본 목록 복귀·접근성 검사 추가
- `docs/spec.md`, `docs/design.md` — 자취 요리 진입 기준
- 이 작업 기록

## 정한 것·남은 것
- ‘자취 요리’는 새 음식 카테고리 데이터가 아니라 기존 일상 레시피 모음의 공개 진입점으로 구현했다. 새 데이터 구조·패키지·API 호출은 추가하지 않았다.
- 기존 음식의 추가·수정은 그대로 공개 콘텐츠 또는 관리자 편집으로 진행한다. 이번 작업은 새 레시피 수집·자동 생성 범위를 늘리지 않는다.
- 시작 및 push 전 확인한 원격 기준: `5b991bcc3023ea4b3c64f16f45c300b7f3d4b494`. 원격에 새 팀원 커밋·변경 파일 없음. 가져올 팀원 변경·충돌 없음.
- 원래 폴더의 기존 미커밋 변경은 건드리지 않고 깨끗한 별도 worktree에서 작업했다. 커밋 후 `git pull --rebase origin main`으로 최신 통합 상태를 확인하고 공통 pre-push 훅 전체 검사를 통과한 결과만 push한다. 원격이 바뀌면 통합·검사를 반복한다.
