# 신규 음식 하루 3개의 사진 확보·게시 처리

- 날짜: 2026-11-23
- 누가: Codex

## 한 것
- 원고 최대 3개와 사진 생성 1회가 맞지 않아 새 원고의 게시가 밀리는 문제를 수정했다. 오늘 검증한 새 원고를 사진 검색·생성에 먼저 배정하고, 자리가 남으면 원문을 재확인한 대기 원고로 채운다. 기존 사진 검색 5개 한도는 유지한다.
- 실사가 없으면 최대 3개의 음식 사진을 생성한다. 품질 탈락에만 지적을 반영해 음식당 한 번 보완한다. 생성 성공 최대 3개·유료 요청 총 6회이고 실패도 차감한다. API 오류·시간 초과는 재시도하지 않는다. 일일 예약으로 중단·재실행의 중복 호출을 막는다.
- 한국 날짜 기준 최종 신규 공개도 최대 3개로 제한한다. 같은 날 재실행은 남은 자리만 사용하고, 초과 원고와 실패 원고는 캐시에 보존한다. 보고서·Actions 요약에 공개 대상 수·부족 건수와 보류 사유를 표시한다. 공개 대상은 전체 검사·저장·배포 전의 수치임을 명시한다.
- 사진이 없는 세 원고가 각각 품질 보완을 거쳐 생성·사진 등록·최종 공개 대상 반영까지 이어지는 통합 테스트를 추가했다. 한 음식 실패 후 대체 원고로 세 자리를 채우는 경우, 재실행 한도, 한국 자정의 초기화, API 오류·예약 복원도 확인했다.
