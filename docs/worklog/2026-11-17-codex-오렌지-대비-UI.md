# 소개 문구 제거와 오렌지 대비 강화

- 날짜: 2026-11-17
- 누가: Codex
- 관련: docs/plan.md 검증 / docs/spec.md R1·R2·R4 / 사용자의 UI 재검토 요청

## 한 것
- 요청한 ‘요즘 눈길 가는 맛.’과 ‘궁금했던 유행 음식부터 직접 만들어 볼 레시피까지.’를 홈에서 제거했다. 헤더 다음에 대표 음식이 바로 보인다.
- 대표 음식 면은 선명한 오렌지, 음식명·주 버튼은 잉크색으로 변경했다. 로고와 연결되는 오렌지 경계와 선택 상태를 적용했다.
- 음식명은 PC 64px·모바일 40px로 키우고 목록 주 버튼도 잉크색으로 채웠다. ‘음식 둘러보기’는 대표 패널 아래로 옮겼다.
- 기존 검색·필터·찜·사진 안내·재료 구매 동작은 유지했다. 유료 수집·이미지 생성 API는 호출하지 않았다.

## 바뀐 파일
- `web/src/app/theme.css` — 대표 오렌지·브랜드·분류 토큰과 음식명 크기
- `web/src/components/home/home-feed.tsx` — 소개 문구 제거·대표 패널 대비·탐색 링크 위치·선택 상태
- `web/src/components/home/food-card.tsx` — 주 버튼의 색 대비 강화
- `web/e2e/mvp.spec.ts` — 문구 제거·헤더와 대표 패널 간격·첫 화면 CTA·테마 검증
- `web/content-e2e/content.spec.ts` — 실제 콘텐츠에서도 문구 제거·첫 화면 CTA·스크린샷 확인
- `docs/design.md` — 사용자 피드백에 따른 최신 색상·배치 기준
- `docs/worklog/2026-11-17-codex-오렌지-대비-UI.md` — 작업 기록

## 정한 것·남은 것
- 사용자가 색이 밋밋하다고 지적해 대표 패널에 오렌지를 넓게 쓰고 잉크색으로 대비를 주는 방향으로 해석했다. 새 패키지·이미지·음식 데이터 변경은 없다.
- 원래 작업 폴더의 필터 접기 관련 미커밋 변경은 보존하고 이번 변경만 동기화했다. 배포 커밋에는 이번 변경만 포함한다.
- main 반영 후 GitHub CI·배포 결과와 운영 주소의 모바일·PC를 확인한다.
