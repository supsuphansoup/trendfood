# 최근 영상에서 유행 음식 후보 찾기

- 날짜: 2026-11-12
- 누가: Codex
- 관련: docs/spec.md R12·R17

## 한 것
- 최근 7일 인기 검색에 최근 48시간 최신순 검색을 더하고 영상 ID로 중복을 제거했다.
- 상승 기준을 충족한 후보를 먼저 고른 뒤 최신 영상에서 이름이 확인된 후보를 남은 자리에 담았다.
- 아직 기준을 넘지 않은 후보는 관리자 큐에 '상승률 확인 전'으로 표시한다. 같은 주에 다시 추출되고 상승 기준을 넘은 자동 수집 대기 후보는 기존 행을 갱신한다.
- 대기 후보에는 AI 상세 초안을 생성하지 않는다. 확정 후보에는 점수 대신 실제 검색 상승 배수를 표시한다.

- 기존 검색어 5개와 합계 10개 상한을 유지했다. 상승 후보가 10개면 상승률 확인 전 후보는 해당 실행에서 추가하지 않는다.
