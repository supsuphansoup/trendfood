# 추천 사진 위에서도 홈 자동 넘김 동작

- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R1, 기준 원격 `1134da08cec192d42df09c48c129420dffdf6e51`

## 한 것

- 운영 사이트에서 헤더에 커서를 두면 8초 뒤 2장으로 넘어가고, 추천 사진 위에 커서를 두면 같은 시간 뒤에도 첫 장에 머무는 것을 재현했다.
- 추천 영역에 커서가 들어오면 타이머를 멈추던 조건을 제거했다. 사용자는 일시정지 버튼으로 직접 멈추고 버튼 위에 커서를 둔 채 재개할 수 있다.
- 테스트를 수정한 뒤 이전 코드에서 8초 후 2장 기대값이 1장으로 남는 실패를 확인했고, 수정 후 PC·모바일에서 같은 검사가 통과했다.

## 바뀐 파일

- `web/src/components/home/home-feature.tsx` 커서 위치와 타이머를 분리한다.
- `web/e2e/mvp.spec.ts` 사진 위에서의 자동 넘김과 버튼 위에서의 재개를 검사한다.
- `docs/design.md` 자동 넘김과 일시정지 조건을 기록한다.

## 검사 결과

- `git diff --check`, `npm run lint`, `npm run typecheck` 통과
- `npm run test:unit` 220개 통과
- `npm run test:e2e` 163개 통과, 모바일 전용 검사 1개는 PC에서 건너뜀
- `npm run test:content` 45개 통과, 와이드 PC 전용 검사 1개는 모바일에서 건너뜀
- `web/test-results/content/`의 `hero-fullscreen-mobile.png`와 `hero-fullscreen-desktop.png`에서 추천 영역과 정지 버튼을 확인했다.

## 정한 것

- 영역 전체의 마우스 오버 대신 명시적인 일시정지 버튼을 사용한다. 키보드 이동, 직접 넘김, 동작 줄이기 및 탭이 숨겨질 때의 정지 동작도 검사했다.
- 작업 기준 이후 들어온 팀원 커밋과 충돌 없음.
