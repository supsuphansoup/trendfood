# 첨부한 로고를 사이트와 탭 아이콘에 적용

- 날짜: 2026-11-16
- 누가: Codex
- 관련: docs/spec.md R1·R4·R8 / docs/design.md 0장

## 한 것
- 사용자가 첨부한 주황색 로고를 홈·음식 상세·소개·개인정보처리방침·이용약관 페이지의 홈 링크에 적용했다.
- 원본 PNG를 그대로 보존했다. SVG는 원본 바이트를 포함하고 표시 영역만 조정해 큰 투명 여백 때문에 로고가 작게 보이지 않게 했다. 원본 색·형태·투명도를 변경하거나 생성형 도구·API를 사용하지 않았다.
- 기존 기본 favicon을 제거하고 동일한 로고를 브라우저 탭 아이콘으로 지정했다. 서비스명과 홈 이동 링크, 44px 이상 클릭 영역을 유지했다.

## 바뀐 파일
- `web/public/brand/trendfood-logo.png`, `web/public/brand/trendfood-logo.svg` — 첨부 원본과 표시용 SVG.
- `web/src/components/site-logo.tsx` — 공통 장식 이미지. 서비스명 텍스트로 링크의 접근 가능한 이름을 유지.
- `web/src/components/home/home-feed.tsx`, `web/src/components/site-info-page.tsx`, `web/src/app/food/[slug]/page.tsx` — 홈·안내·상세 로고 연결.
- `web/src/app/layout.tsx`, `web/src/app/favicon.ico` — 새 탭 아이콘 설정과 기본 아이콘 제거.
- `web/e2e/mvp.spec.ts` — 5개 공개 경로에서 로고 로딩·홈 링크·최소 높이·가로 넘침·탭 아이콘 검사. SVG에 포함된 원본 바이트도 확인.
- `docs/design.md` — 첨부 로고 사용 기준.

## 정한 것·남은 것
- 사용자의 로고 교체 요청에 따라 탭 아이콘과 공개 페이지의 서비스명 옆 심볼을 통일했다. 음식 데이터와 사진은 변경하지 않았다.
- 원본의 투명 여백은 SVG 표시 영역에서만 제외했다. 별도 비용이 드는 생성·검색 호출은 없다.
