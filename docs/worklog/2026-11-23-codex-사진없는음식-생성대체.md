# 참고 사진이 없는 음식도 설명으로 생성하는 자동화

- 날짜: 2026-11-23
- 누가: Codex
- 관련: `docs/spec.md` R1·R4·R14 / `docs/automation.md`

## 한 것
- 사용자 추가 요청에 따라 실사 검색 후 참고 사진이 없어도 원문 검증된 음식 설명으로 이미지를 생성한다. 정확한 참고가 있으면 우선 사용한다.
- 참고 없는 요청은 공식 Images generations JSON API, 참고 있는 요청은 기존 edits API를 사용한다. 기존 하루 유료 요청 1회·실패 차감·재시도 금지·실사 보호를 유지한다.
- 설명 기반 결과도 음식·레시피·PC/모바일 구도·글자·왜곡을 검사한다. 참고 사진이 없는 사실과 생성 근거를 기록하며 출처·작가·라이선스를 만들지 않는다.
- 불일치 참고 거절 후 설명 생성, 검색 장애/결과 없음, 여러 후보 중 참고 우선, 결과 탈락/같은 날 재호출 차단을 검사한다.

- 사용자 요청의 사진 미확보는 참고 실사도 없는 상황을 포함한다. 신규 트렌드·최근 제작자 2명·원문 검증·전체 검사 조건은 유지한다.
