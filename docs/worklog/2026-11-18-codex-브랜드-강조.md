# 로고 오렌지와 대표 음식으로 홈 강조

- 날짜: 2026-11-18
- 누가: Codex
- 관련: docs/spec.md R1·R2 / docs/plan.md 공개 화면

## 한 것
- 강조가 약하다는 요청에 따라 로고 원본 오렌지를 대표 음식의 큰 면에 사용하고, 음식명을 굵게 키웠다. 검정 주 버튼과 흰 사진 프레임으로 행동·사진을 구분했다.
- 추천 날짜·근거·출처·AI 안내는 대표 면 아래 별도 줄로 옮겨 보존했다. PC 설명 왼쪽/사진 오른쪽, 모바일 사진→설명과 기존 음식 목록 배치는 유지했다.
- 설명 18px·안내 14px, 출처·생성 예시 표시, 검색·필터·찜·재료 담기 동작을 보존했다.

## 바뀐 파일
- `web/src/app/theme.css` — 대표 배경·모서리·제목 크기 토큰.
- `web/src/components/home/home-feed.tsx` — 대표 강조 면·흰 사진 프레임·추천 안내 위치.
- `web/e2e/mvp.spec.ts` — 브랜드 색·사진 프레임·대표 제목·버튼·출처 안내 위치 회귀 검사.
- `web/content-e2e/content.spec.ts` — 실제 콘텐츠의 대표 색·안내 위치 검사와 캡처.
- `docs/design.md` — 색·타이포·배치 결정.
- 이 작업 기록.
