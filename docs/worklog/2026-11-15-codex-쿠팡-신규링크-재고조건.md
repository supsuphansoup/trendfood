# 쿠팡 신규 링크 등록의 재고 확인 조건

- 날짜: 2026-11-15
- 누가: Codex
- 관련: docs/spec.md R6·R11, docs/coupang-automation.md

## 한 것
- 검색 색인에 상품이 있다는 사실만으로 신규 링크를 등록하던 경로에 재고 확인 조건을 추가했다.
- 구매 가능이 명확히 확인된 후보만 대조하고, 등록 직전에 같은 상품 옵션을 다시 확인한다. 품절·미확인·조회 실패는 등록하지 않는다.
- 현재 실행기에는 실시간 재고 확인 수단이 없으므로 신규 등록을 보류하고 상품 검색·AI 대조 비용도 소모하지 않는다. 실시간 재고 조회를 구현하거나 검증했다고 보고하지 않는다.
- 기존 링크·콘텐츠와 예약 시각·검색 한도는 유지했다.

## 바뀐 파일
- `web/scripts/coupang-automation.ts` — 후보·등록 직전 재고 조건과 확인기 미연결 시 보류.
- `web/scripts/auto-coupang.ts` — 신규 등록 보류 사유를 실행 보고서와 출력에 표시.
- `web/scripts/coupang-automation.test.ts` — 품절·미확인·실패·등록 직전 변경·대체 후보·호출 방지 검사.
- `web/scripts/web-products.test.ts` — 키가 있어도 재고 확인 없이 신규 등록·유료 호출하지 않는 CLI 검사.
- `docs/coupang-automation.md` — 현재 보류 상태와 신규 등록 조건 설명.
- 이 작업 기록.

## 정한 것·남은 것
- 사용자 요청을 신규 등록 시점의 조건으로 해석했다. 기존 링크 교체나 주기적 재검사는 이번 범위에 포함하지 않는다.
- 현재 허용된 연결 방식에는 실시간 재고 확인기가 없다. 공식적으로 허용된 확인 수단이 연결되기 전에는 새 링크를 자동 등록하지 않는다.
- 모든 외부 호출은 테스트에서 대체했다. 실제 OpenAI·쿠팡 API 호출 및 쿠팡 스크래핑은 하지 않았다.
