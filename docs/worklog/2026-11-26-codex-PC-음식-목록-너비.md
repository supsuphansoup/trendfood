# PC 음식 목록 너비 확대

- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R2, 기준 원격 `22662b7c85a9dee14d5e93135deafbd4f5bfcba3`

## 한 것

- PC에서 음식 목록과 카테고리·필터의 실제 내용 폭 한도를 1160px에서 1600px로 넓혔다.
- 1280px 이상에서는 2열과 3열 카드 사진 높이도 화면에 맞춰 커진다. 사진은 원본 비율로 중앙에 표시한다.
- 운영 홈에서 실제 시간으로 최상단 추천 음식 자동 넘김을 확인했다. PC 8.02초, 모바일 8.10초에 다음 음식으로 전환했다.

## 바뀐 파일

- `web/src/components/home/home-feed.tsx` 음식 목록 레이아웃 너비를 조정한다.
- `web/src/components/home/food-card.tsx` 데스크톱 카드 사진 높이와 이미지 크기 힌트를 조정한다.
- `web/content-e2e/content.spec.ts` 390px·1280px에서의 목록 폭과 1920px에서의 2열·3열 사진 및 목록 치수를 확인한다.
- `docs/design.md` 음식 목록 너비와 사진 배치 기준을 기록한다.

## 정한 것

- 목록 박스의 최대 폭 1640px 중 좌우 여백은 각각 20px 이상 확보한다.
- 1280px부터 사진 높이를 넓은 화면에 맞춰 늘린다.
- 작업 기준 이후 들어온 팀원 커밋과 충돌 없음.
