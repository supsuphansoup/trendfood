# 유행 음식과 일상 레시피 분리

- 날짜: 2026-11-25
- 누가: Codex
- 관련: docs/spec.md R1·R2

## 한 것

- 상단의 ‘자취 요리’를 ‘일상 레시피’로 바꾸고 목록 아래에 있던 중복 탭을 없앴다. `?collection=everyday` 주소는 기존과 같이 열린다.
- 기본 홈은 유행 음식을 모으며, 일상 레시피 탭을 열면 유행 대표 카드·모음·연도 필터가 사라진다.
- 유행 음식은 확인된 최신 유행 연도부터, 같은 연도에서는 기존 추천 순서대로 보여준다. 전체 검색·찜·보유 재료 찾기는 두 목록을 대상으로 한다.
