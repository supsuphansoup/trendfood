# 여러 음식의 재료를 모으는 통합 장바구니

- 날짜: 2026-11-05
- 누가: Codex
- 관련: 사용자 직접 요청 / docs/spec.md R6

## 한 것
- 음식 상세에서 현재 선택된 재료를 통합 장바구니에 담는 버튼을 추가했다.
- 공개 화면의 장바구니 버튼으로 목록 확인·개별 삭제·원래 음식 상세 이동이 가능하다.
- 브라우저 저장소를 이용해 새로고침해도 유지하며, 같은 음식의 같은 재료는 중복 저장하지 않는다.
- 관리자 화면에는 장바구니를 표시하지 않는다.
- 쿠팡 링크를 자동으로 열거나 외부 장바구니로 일괄 전송하지 않는다.

## 바뀐 파일
- `web/src/components/shopping-cart.tsx` — 통합 장바구니 표시와 삭제.
- `web/src/app/layout.tsx` — 공개 화면에 장바구니 연결.
- `web/src/components/detail/ingredient-cart.tsx` — 선택 재료 담기.
- `web/e2e/mvp.spec.ts` — 여러 음식 담기·중복 방지·저장 유지·삭제·빈 상태·접근성 검사.
- `docs/worklog/2026-11-05-codex-통합장바구니.md` — 작업 기록.

## 정한 것·남은 것
- 사용자 선택: 여러 음식의 재료를 모으는 통합 장바구니.
- 구현 결정: 로그인 없이 현재 브라우저에 저장하며, 다른 음식에서 담은 같은 이름의 재료는 출처 음식별로 구분한다. 수량 합산이나 결제는 추가하지 않았다.
- 설치된 Next.js 문서의 Link와 use client 사용법을 확인했다.
- 최초 npm 실행 경로 오류를 바로잡은 뒤 검사 4개를 완료했다.
- 사용자 지시에 따라 Git 조작·커밋·배포 사이트 변경 없음. 로컬 개발 서버만 실행한다.
