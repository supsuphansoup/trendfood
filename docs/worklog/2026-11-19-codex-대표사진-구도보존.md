# 메인 대표 사진의 원본 구도 보존

- 누가: codex (AI 도구: Codex)

## 한 것
- 메인의 대표 사진을 원본 비율과 중앙 정렬로 표시하고, 사진 전체를 담도록 변경했다. 가로·세로 사진과 생성 예시에 동일하게 적용한다.
- 고정 비율 틀과 흐린 복제 배경을 없애 음식 구도가 어색하게 보이는 문제를 줄였다. 사진 전체를 누르는 상세 이동은 유지했다.
- 대표 사진의 비율·높이 제한·중앙 정렬과 가장자리 클릭·키보드 이동을 공개 콘텐츠 검사에 추가했다.

- `web/src/components/home/home-feed.tsx` — 고정 비율 대신 사진 자체 높이를 사용하는 대표 영역.
- `web/e2e/mvp.spec.ts` — 예시 콘텐츠 대표 사진의 전체 표시 확인.

## 팀원 변경·통합
- 작업 시작 전과 커밋 전 `git fetch origin main`으로 기준 커밋을 확인했다. 새 팀원 커밋·겹치는 변경 없음. 별도 worktree에서 작업해 기존 작업 폴더의 미커밋 변경을 보존했다.
- 충돌 해결 없음. 커밋 후 원격 재확인·rebase 및 공통 pre-push 전체 검사를 거쳐 push한다.

## 정한 것·남은 것
- 대표 사진을 메인 대표 영역으로 해석했다. 다른 사진 구도는 변경하지 않았다.
- 화면 대부분을 사진이 차지하지 않도록 모바일 최대 280px·PC 최대 400px로 제한했다. 남는 여백은 기존 보조 배경색을 사용한다.
- 배포 후 실제 서비스에서 모바일·PC 사진 크기와 상세 이동을 재확인한다.
