# 파트너스 승인 전 일반 쿠팡 검색 연결 유지

- 날짜: 2026-11-12
- 누가: Codex
- 관련: 팀장의 파트너스 미승인 안내 / `ea86017`

## 한 것
- GitHub 변수 `PIPELINE_AUTO_COUPANG`을 `true`에서 `false`로 변경했다. 파트너스 API 자동 검색·제휴 링크 발급을 중지하고 일반 쿠팡 검색 연결을 유지한다.
- 기존 `coupangUrl`이 재료명을 검색어로 자동 생성하고 구매 버튼에서 사용하는 것을 확인했다. 공개 음식 30개에 직접 등록된 재료 URL은 0개라 현재 모두 일반 검색으로 연결된다. 앱 코드·일일 음식/사진 수집 설정은 변경하지 않았다.

## 바뀐 파일
- `docs/coupang-automation.md` — 현재 중지 상태와 일반 검색 운영을 명시했다.
- 이 작업 기록. 저장소 밖 설정은 GitHub Actions 변수 한 개다.

## 검사 결과
- `gh variable get PIPELINE_AUTO_COUPANG`: `false`.
- `gh workflow run pipeline.yml --ref main -f links_only=true`: [실행 43232936453](https://github.com/supsuphansoup/trendfood/actions/runs/43232936453) 성공. 쿠팡 캐시 복원·API 연결·기록 보존 단계 모두 `skipped`를 확인했다.
- `npm run test:e2e -- --grep "쿠팡 이동"`: 빌드 성공, `2 passed (10.3s)`. PC·모바일에서 재료별 검색어·사용자 클릭당 링크 한 개·이동 순서를 확인했다. 외부 쿠팡 페이지 응답은 테스트에서 모의 처리했다.
- lint·typecheck·test:unit: 앱 코드 미변경으로 재실행하지 않았다. 직전 구현의 로컬·GitHub 전체 검사는 통과했고, 이번 변경은 관련 브라우저 검사로 검증했다.

## 정한 것·남은 것
- 파트너스 승인·API 이용 가능 여부가 해결될 때까지 제휴 자동화를 꺼두는 것으로 해석했다. 일반 검색 연결에는 제휴 수익이 없다.
- 승인 상태 자체를 외부 계정에 로그인해 확인하거나 제휴 링크를 새로 발급한 것은 아니다. 재개 시 기존 연결 문서를 따라 키·등록 채널·실제 응답을 확인한다.
