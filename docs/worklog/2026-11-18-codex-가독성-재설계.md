# 최근 사이트 비교와 음식 탐색 가독성 재설계

- 날짜: 2026-11-18
- 누가: Codex
- 관련: docs/spec.md R1·R2 / docs/plan.md 7단계

## 한 것
- 작은 회색 안내와 구분이 약한 링크를 지적받아 음식 서비스 외 최근 수상 사이트까지 비교했다. Awwwards의 최근 선정작 Bulletproof, 2026 Webby 인기상 Maeve Chocolate, Cosmos·Airbnb·SideChef 실제 화면을 열었다. 수상 여부와 단순 참고 서비스는 구분했고 주소·채택 원칙을 `docs/design.md`에 기록했다.
- 본문을 18px/1.75, 날짜·사진 안내를 최소 14px로 올리고 본문 명암·자간을 보정했다. 목록 설명의 두 줄 생략을 없앴다.
- 선호했던 대표 좌우 분할·모바일 사진 우선·목록 PC 2열/모바일 1열·세 번째 넓은 배치를 보존했다. 목록은 옅은 바탕, 음식은 흰 면으로 묶고 사진→제목/설명→시간→행동 순서를 명확히 했다.
- 대표의 추천 날짜·근거·출처·AI 안내를 별도 줄로 분리했다. 읽기 버튼은 채움, 재료 버튼은 테두리로 구분하고 48px 높이를 확보했다. 원본 로고·생성 안내·검색·필터·찜·구매 동작을 유지했다.

## 바뀐 파일
- `web/src/app/theme.css` — 본문·안내·목록 배경과 글자 토큰.
- `web/src/components/home/home-feed.tsx` — 대표 정보 위계·안내 분리·목록 바탕·탐색 글자.
- `web/src/components/home/food-card.tsx` — 설명 크기·전체 노출·내부 간격·행동 버튼 구분.
- `web/e2e/mvp.spec.ts` — 모바일/PC 본문 크기·줄 간격·생략 방지·버튼 이동·접근성 검증.
- `web/content-e2e/content.spec.ts` — 실제 모든 목록 음식 설명의 18px·생략 방지와 사진 안내 검증.
- `docs/design.md` — 실제 참고 사이트와 색·글자·구성 계획.
- 이 작업 기록.

## 정한 것·남은 것
- 임의 결정: 최근 수상작의 강한 제목·명확한 행동 구분과 실제 탐색 서비스의 정보 묶음을 채택했다. 선호 배치는 유지하고 작은 글자로 밀도를 높이던 접근을 바꿨다.
- 유료 API·사진 생성·패키지 추가는 없다. 음식 수집·원본 사진·상품 연결 설정은 이번 범위에서 변경하지 않았다.
- 운영 배포 결과는 이어서 기록한다.
