# 정렬·태그·연도 필터를 카테고리 아래로 이동

- 날짜: 2026-11-16
- 누가: Codex
- 관련: docs/spec.md R1·R2 / docs/design.md 0장

## 한 것
- PC에서 추천순·조리시간순, 10분컷 등 태그, 연도 필터를 왼쪽 카테고리 아래로 옮겼다.
- 왼쪽 영역이 화면보다 길면 내부에서 스크롤하도록 하고, 음식 목록의 PC 스크롤 여백을 조정했다.
- 모바일은 카테고리 아래에 정렬·태그, 연도 필터를 가로 줄로 배치했다.
- PC·모바일 카테고리 DOM을 하나로 합치고 주소 보존·검색·필터 동작을 유지했다.

## 바뀐 파일
- `web/src/components/home/home-feed.tsx` — 반응형 필터 배치와 목록 스크롤 여백.
- `web/e2e/mvp.spec.ts` — 연도 슬라이더를 음식 필터 영역에서 찾도록 조정.
- `web/content-e2e/content.spec.ts` — 카테고리 아래 배치·10분컷 조리시간 정렬·연도 선택·가로 넘침 테스트와 스크린샷 추가.
- `docs/design.md` — 필터 위치 기준 반영.
- `docs/worklog/2026-11-16-codex-카테고리-아래-필터.md` — 작업 기록.
