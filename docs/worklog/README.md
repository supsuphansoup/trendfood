# 작업 기록 (worklog)

팀원이 한 작업을 팀장이 한눈에 볼 수 있게 남기는 곳이에요. **AI가 작업을 끝낼 때마다 이 폴더에 파일을 하나 새로 만들어요** (규칙은 `AGENTS.md` "작업 기록 남기기").

- 파일 이름: `YYYY-MM-DD-이름-주제.md` (예: `2026-11-06-hj-영상임베드.md`). 이름은 `git config user.name` 또는 정한 별명.
- 한 작업 = 파일 하나. 남의 파일은 고치지 않아요 (여러 명이 동시에 push 해도 충돌이 안 나요).
- 같은 작업을 이어서 하면 내 파일 아래에 `## 이어서 (날짜)` 를 덧붙여요.
- 작업과 **같은 커밋** 에 넣어요.

## 틀 (복사해서 쓰기)

```markdown
# <주제 한 줄>

- 날짜: YYYY-MM-DD
- 누가: <이름> (AI 도구: <ChatGPT/Codex/Cursor 등>)
- 관련: docs/plan.md <단계> / docs/spec.md <R번호> / 커밋 <해시>

## 한 것
- (무엇을 왜 바꿨는지 2~5줄)

## 바뀐 파일
- `경로` — 한 줄 설명

## 검사 결과
- lint / typecheck / test:unit / test:e2e: 통과 또는 실패(이유)

## 정한 것·남은 것
- 임의로 정한 것, 팀장·회의에서 확인받아야 할 것, 못 끝낸 것
```
