# 홈 음식 목록 사진의 원본 비율 보존

- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R2, 기준 원격 `ae4470774dbc40af11c77a7ab3dbd10ce72fa778`

## 한 것

- 홈 음식 목록 카드에서 사진을 중앙에 맞추어 원본 전체를 표시한다. 마우스를 올리거나 누를 때 사진을 확대하던 효과를 제거했다.
- 2열과 3열의 사진 영역 전체는 음식 상세 링크로 사용한다.

## 바뀐 파일

- `web/src/components/food-image.tsx`, `web/src/components/home/food-card.tsx`, `web/src/components/home/home-feature.tsx` 사진 배치 방식을 지정한다.
- `web/src/app/globals.css` 카드 사진 확대 효과를 제거한다.
- `web/content-e2e/content.spec.ts` 세로 사진의 2열·3열 표시, 가리키기, 상세 이동을 검사한다.
- `docs/design.md` 목록 카드 사진 표시 기준을 기록한다.

## 정한 것

- 사진과 카드 영역의 비율이 다른 경우 기존 카드 보조 배경색으로 여백을 채운다.
- 작업 기준 이후 들어온 팀원 커밋과 충돌 없음.
