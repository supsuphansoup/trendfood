# 사진 대기 음식에 참고 기반 생성 예시 연결

- 날짜: 2026-11-20
- 누가: Codex
- 관련: 사용자 실제 메뉴 참고 생성 사진 요청 / docs/automation.md

## 한 것

- 실제 메뉴 공개 사진을 확인하고 대화의 image_gen 도구로 요거트 찹쌀떡·생초코 찹쌀떡·크런치 27 큐브 예시 3장을 생성했다. 기존 사진의 형태·속재료만 참고해 새 구도로 생성했다. 프롬프트와 참고 주소를 등록부에 보존하고 원본 참고 사진은 서비스에 올리지 않는다.
- 같은 음식으로 등록한 생성 사진이 있으면 빈 사진만 연결한다. 기존 실사 사진은 보존한다. 상세의 접힌 정보·대체 설명에 AI 생성 예시를 표시한다.
- `pending_only`는 추가 AI 호출 없이 공식 출처를 재확인하고 등록한 사진이 있는 대기 음식만 공개한다. 실제 게시 여부는 실행 결과로 확인한다.

## 바뀐 파일

- `.github/workflows/pipeline.yml`, `web/scripts/restore-pending-photos.ts` — 사진 대기 원고 전용 실행, 유료 AI 작업 건너뛰기.
- `web/scripts/pipeline/recommendations{,.test}.ts` — 등록 이미지 연결·출처 재확인·중복 방지·비용 경로 검사.
- `web/src/assets/generated/photo-ai-{yogurt-mochi,nama-chocolate-mochi,crunch-27-cube}.webp`, `web/src/data/content/generated-images.json`, `web/src/lib/generated-photos.ts` — 생성 예시 3장·기록·번들.
- `docs/automation.md` — 적용 절차·예약 생성 자동화와의 차이.
