# 실제 사이트 비교를 바탕으로 홈 화면 정리

- 날짜: 2026-11-18
- 누가: Codex
- 관련: docs/plan.md 7단계 / docs/spec.md R1·R2

## 한 것
- 사용자가 자동 생성 시안 같은 인상을 지적해 우리의식탁·29CM·Bon Appétit·Eater의 실제 PC 화면과 우리의식탁·29CM 모바일 화면을 비교했다. 참고 주소와 채택한 원칙은 `docs/design.md` 최신 항목에 기록했다.
- 선호했던 단일 대표 좌우 분할과 PC 2열/모바일 1열·세 번째 넓은 음식 배치를 보존했다. 큰 주황 배경·카드 바깥 상자·반복 채움 버튼·카테고리 아이콘을 줄이고 음식 사진과 제목의 위계를 정리했다.
- 중성 먹색·행동용 오렌지로 토큰을 정리하고 대표 사진 안내를 사진 아래 캡션으로 옮겼다. 원본 로고·출처·추천 날짜·생성 예시 안내·재료 구매 동작은 유지했다. 유료 API 호출·사진 생성·새 패키지는 없다.

## 바뀐 파일
- `web/src/app/theme.css` — 색상과 홈 모서리 토큰.
- `web/src/components/home/home-feed.tsx` — 대표·검색·카테고리·목록 제목 정리.
- `web/src/components/home/food-card.tsx` — 사진과 텍스트 링크 중심 카드.
- `web/e2e/mvp.spec.ts` — 캡션 위치·주요 클릭 영역·단일 대표·기존 열 배치·접근성 검증.
- `web/e2e/admin.spec.ts` — 공통 주 버튼의 최신 색·호버 접근성 검증.
- `web/content-e2e/content.spec.ts` — 실제 콘텐츠의 사진 안내·기존 탐색·구매 동작 검증.
- `docs/design.md` — 실제 참고 사이트·색/글자/배치 계획·기본 시안 검토 기록.
- 이 작업 기록.
