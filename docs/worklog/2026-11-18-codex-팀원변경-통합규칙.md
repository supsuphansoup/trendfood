# push 전 팀원 변경 확인·통합 규칙

- 날짜: 2026-11-18
- 누가: Codex
- 관련: AGENTS.md 협업·push 절차 / CLAUDE.md 공통 작업 규칙

## 한 것
- 팀원 변경이 겹치거나 누락되지 않도록 작업 시작·push 전 원격 변경 확인, 새 커밋·diff·작업 기록 검토, rebase 통합, 통합 후 검사, push 직전 재확인 순서를 명시했다.
- 같은 파일의 자동 병합도 기능을 검토하고, 파일 통째 덮어쓰기·강제 push를 금지했다. 검사 중 새 원격 변경이나 push 거절이 생기면 통합·검사를 반복한다.
- Codex가 읽는 `AGENTS.md`와 Claude 인수인계 `CLAUDE.md`에 같은 기준을 연결했다.

## 바뀐 파일
- `AGENTS.md` — 팀원 변경 확인·통합 후 push 필수 절차.
- `CLAUDE.md` — 같은 절차를 공통 규칙·원격 저장소 안내에 반영.
- 이 작업 기록.

## 검사 결과
- 문서만 변경: lint / typecheck / test:unit / test:e2e는 문서 전용 검사 예외에 따라 미실행. 앱 코드·설정·동작 변경 없음.
- `git fetch origin main` 성공. 기준 `3eb3d0f`에서 `git log --oneline HEAD..origin/main`, `git diff --name-status HEAD...origin/main` 출력 없음: 아직 가져올 팀원 커밋·충돌 없음.
- 문서의 파일 경로·npm 검사 명령과 Git 비교 명령을 확인했다. `git diff --check` 통과.
- 실제 충돌 상황을 만들어 재현하지 않았으며 자동 hook·CI 강제 차단은 추가하지 않았다. 이번 변경은 AI 작업자가 따를 저장소 MD 규칙이다.

## 정한 것·남은 것
- 팀원이 원격 `origin/main`에 올린 변경을 기준으로 한다. 팀원 PC의 미커밋·미푸시 작업은 자동 확인할 수 없다.
- 원래 작업 폴더의 다른 미커밋 변경은 보존하고 깨끗한 기존 worktree에서 문서만 수정했다.
- push 전 원격 재확인: `origin/main = 3eb3d0fbb2680a0aacd5ccfa0ef2ac61a1f94ed7`, 가져올 팀원 커밋·충돌 없음. 이 문서 변경도 커밋 후 rebase·경로 검사·원격 재확인을 거쳐 push한다.
