# 색상 변경을 넘어 음식 탐색 구조 개편

- 날짜: 2026-11-17
- 누가: Codex
- 관련: docs/plan.md 검증 / docs/spec.md R1·R2·R3 / 사용자의 ‘색만 바꾸지 말고 UI를 바꿔달라’는 요청

## 한 것
- 단일 대표 배너를 대표 사진 1개와 보조 음식 2개의 비대칭 구성으로 바꿨다. 모바일에서는 보조 음식 2개가 나란히 보여 첫 화면에서 세 음식 사진을 탐색한다.
- 대표 사진을 어둡게 덮지 않고 원본 구도를 중앙에 보존한다. 제목과 주 동작은 별도 잉크색 캡션에 두고 기존 슬로건 삭제를 유지했다.
- 음식 목록은 모바일 2열·PC 3열이다. 중첩 상자·큰 채움 버튼·모바일의 긴 설명을 줄이고 사진·음식명·찜·상세 탐색을 우선했다. 재료 링크는 모바일에서 아이콘과 접근 가능한 이름으로, PC에서 원래 문구로 제공한다.
- 카테고리를 항상 보이는 가로 탐색으로 옮기고 정렬·태그·연도만 접는 필터로 구성했다. 원래 폴더의 필터 접기 작업을 바탕으로 주소·조건 보존을 이어갔다.
- 인피드 광고는 행이 깨지지 않게 목록 음식 6개 다음에 1개만 둔다. 사진·음식·상품 데이터·자동화·상세 기능은 변경하지 않았다. 유료 AI API·이미지 생성 호출은 없다.

- `web/content-e2e/content.spec.ts` — 실제 음식의 새 구성·필터·이미지 표시·상세/구매 회귀 검사
