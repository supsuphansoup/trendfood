- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R1, `docs/design.md` 홈 헤더

## 한 것

- PC에서는 검색창을 로고 오른쪽으로 옮겼다. 높이 46px, 너비는 화면에 따라 최대 440px다.
- 모바일에서는 로고 아래에 검색창을 한 줄로 넓게 배치하고 헤더 위아래 여백을 줄였다. 검색 버튼은 모든 화면에서 44×44px이다.
- 로컬에서 확인한 홈 음식 이름 옆 순위, 브랜드 로고 정렬, 말차·우베 라떼 사진을 같은 배포 범위에 포함했다.
