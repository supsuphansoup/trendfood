# 배치를 유지하고 화이트·오렌지 색상으로 재개편

- 날짜: 2026-11-17
- 누가: Codex
- 관련: docs/spec.md R1·R2·R4 / docs/design.md 0장

## 한 것
- 사용자가 크림·그린 팔레트에 불만을 밝혀 흰 바탕, 선명한 오렌지 대표 면, 네이비 글자, 오렌지 주 버튼으로 바꿨다. 로고 오렌지는 유지했다.
- 단일 대표 패널·PC 2열·모바일 1열·넓은 세 번째 카드, Pretendard·제목 크기·간격·필터 접기는 유지했다.
- `frontend-design` 스킬로 색상 역할을 먼저 정하고 검토했다. 기존 시안의 흐린 면과 여러 색조를 줄이고 대표 면·행동·선택에 오렌지를 집중했다. 대표 주 버튼은 네이비로 구분한다.
- 첫 브라우저 검사에서 일부 공통 버튼의 반투명 호버와 모바일 구매 안내 글자의 대비 부족을 발견했다. 공통 버튼은 불투명한 진한 호버로, 구매 안내 글자는 주 버튼 전용 흰 토큰으로 수정했다. 관리자 로그인 버튼의 기본·호버 접근성 회귀 검사를 추가했다.
- 유료 API·이미지 생성·수집 자동화·음식 데이터 변경은 없다.

## 바뀐 파일
- `web/src/app/theme.css` — 새 팔레트 공유 토큰.
- `web/src/components/home/home-feed.tsx` — 오렌지 면 위 대표 주 버튼의 네이비 색.
- `web/src/components/ui/button.tsx` — 공통 주 버튼 호버 대비.
- `web/src/components/detail/ingredient-cart.tsx` — 모바일 구매 안내 글자 대비.
- `web/e2e/mvp.spec.ts`, `web/e2e/admin.spec.ts`, `web/content-e2e/content.spec.ts` — 새 색상·선택 상태·기본/호버 접근성 회귀 검사.
- `docs/design.md` — 색상 역할·유지할 배치 기준.
- 이 작업 기록.
