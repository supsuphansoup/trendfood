## 한 것
- 기존 실사 검색에서 정확한 음식임을 확인했지만 구도가 부적합한 실제 사진을 생성 참고로 재사용한다. 게시 가능한 실사는 우선하고, 참고 사진도 없는 음식은 계속 보류한다.
- 빈 대표 사진만 OpenAI Images API로 생성한다. 한국 날짜 하루 최대 1회, 실패·결과 탈락도 차감하며 유료 재시도는 하지 않는다. Actions 캐시 예약을 호출 전에 저장하고 서버 확인 실패 시 생성을 중지한다.
- 생성 결과를 원본·설명/조리법·카드/PC/모바일 구도와 다시 대조한다. 통과한 파일·생성 기록·출처/이용 조건·번들·음식 JSON을 함께 저장하고 상세의 접힌 사진 정보에 안내한다.
- 사진 전용 실행도 캐시의 대기 원고를 공식 원문으로 재검증한다. 새 음식 검색·원고 생성·쿠팡 검색을 추가하지 않는다.
- 2026-11-22 pipeline 45001285405의 실제 실패는 ‘최근 발견’ 클릭 직후 갱신 전 목록을 비교한 콘텐츠 e2e였다. 자동 재시도하는 Playwright 목록 assertion으로 수정한다.
