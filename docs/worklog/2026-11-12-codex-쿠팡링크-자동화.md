# 쿠팡 재료 상품·제휴 링크 자동 연결 준비

- 날짜: 2026-11-12
- 누가: Codex
- 관련: 팀장의 "쿠팡 링크도 자동으로 생성해서 연결" 요청

## 한 것
- 기존·신규 음식의 링크 없는 재료를 하루 한 번 기존 예약에서 검색·대조·연결하는 CLI와 워크플로를 추가했다. 동일 이름은 한 번 검색하고 여러 음식에 연결한다. 수동 링크와 조리법·확인 날짜를 보존한다.
- 실제 파트너스 검색 응답의 상품 URL만 사용한다. 정확한 재료명·비식품 제외·조리 문맥 대조를 통과해야 연결하고 가격·상품 사진·AI가 만든 URL은 저장하지 않는다. 미설정·불일치·API 실패는 기존 일반 검색 연결을 유지한다.
- 시간당·실행당 검색 최대 5회, 실패·미리보기 선기록, 순환 검색, 403·429 후 24시간 중단, 호출 기록 캐시, 원문·키 비노출 처리를 추가했다. 단일 캐시가 계정의 다른 도구·로컬 호출까지 집계하지는 않는다.
- 공식 파트너스 PDF에서 API 제공·최종 승인 후 키 발급·검색 시간당 10회 안내를 확인했다. 공식 포털 API 문서는 이 환경에서 Access Denied라 현행 상세 명세를 직접 확인하지 못했다. 공개 클라이언트 작성자의 참조·구현을 대조해 v1 호환 요청을 작성하고, 실제 계정 연결 후 검증이 남았음을 문서에 명시했다.
- 도구 탐색은 `find-skills`로 `npx --yes skills find "coupang affiliate api"` 한 번 실행했다. 외부 스킬·패키지는 설치하지 않았다.

## 정한 것·남은 것
- 2026-11-12 조회한 GitHub Secrets·Variables 이름 목록에는 쿠팡 Access Key·Secret Key·채널 ID가 없다. 값을 읽거나 채팅으로 요청하지 않았다. 가입·발급 상태는 사용자에게 확인 요청했다.
- 실제 키·등록 채널·현행 명세를 확인하고 실제 상품 URL 발급·수익 귀속을 검증하는 단계가 남았다. 키 없는 건너뛰기와 모의 응답 성공을 실제 발급 완료로 표현하지 않는다.
