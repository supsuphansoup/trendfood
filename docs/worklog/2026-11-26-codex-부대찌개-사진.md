# 부대찌개 대표 사진 교체

- 날짜: 2026-11-26
- 누가: Codex
- 관련: 공개 콘텐츠의 일상 레시피 대표 사진

## 한 것

- 먹다 남긴 듯 보이던 부대찌개 대표 사진을 냄비째 차려 낸 한국농수산식품유통공사 실사로 교체했다.
- 공공누리 제1유형과 촬영 기관·연도를 확인했다. 상세 사진 정보에 출처와 이용 조건, 당면·치즈가 레시피와 다른 점을 표시했다.
- 목록 카드와 상세 화면에서 모바일·PC 모두 사진을 표시하는지 확인했다.

## 바뀐 파일

- `web/src/assets/curated/photo-everyday-budae-jjigae-plated-20261126.webp` — 공공누리의 591×394 공개 이미지 구도를 유지해 WebP로 변환
- `web/src/data/content/foods.json`, `web/src/data/content/auto-photo-credits.json`, `web/src/lib/curated-photos.ts` — 음식 사진과 출처 연결
- `web/src/data/photo-credits.ts`, `web/src/data/photo-source.ts` — 공공누리 원본 페이지와 이미지 주소 및 이용 조건을 검증하는 수동 등록
- `web/scripts/content.test.ts`, `web/content-e2e/content.spec.ts` — 이용 조건 검사와 모바일·PC 사진 및 출처 표시 검사
