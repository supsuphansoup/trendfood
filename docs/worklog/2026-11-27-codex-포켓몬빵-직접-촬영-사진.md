# 포켓몬빵 직접 촬영 사진 적용

- 날짜: 2026-11-27
- 누가: Codex
- 관련: docs/spec.md R4·R14

## 한 것

- 사용자가 직접 촬영한 삼립 돌아온 로켓단 초코롤 포장 사진을 포켓몬빵 목록 카드와 상세 대표에 연결했다.
- 위아래 배경 여백만 줄이고 포장 전체를 보존했다. 1600×1600 WebP(310702바이트)로 변환하면서 EXIF·XMP를 제외했다.
- 상세에 ‘사용자 제공 · 직접 촬영’을 표시했다. 기존 삼립 제품 출처와 영상 연결도 검사했다.

## 바뀐 파일

- `web/src/assets/direct/photo-pokemon-bread-rocket-choco-roll.webp` · 공개용 직접 촬영 사진.
- `web/src/data/content/foods.json` · 포켓몬빵 이미지 키와 대체 설명.
- `web/src/data/photos.ts`, `web/src/data/content.ts`, `web/src/lib/foods.ts` · 직접 촬영 번들 키 등록과 출처 연결.
- `web/src/app/food/[slug]/page.tsx` · 상세의 접힌 사진 정보에 직접 촬영 안내.
- `web/scripts/content.test.ts`, `web/scripts/photos.test.ts`, `web/content-e2e/content.spec.ts` · 사진 파일·출처·목록과 상세 표시 검사.
