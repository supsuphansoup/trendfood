# 승인 전 일반 쿠팡 상품 상세주소 자동 연결

- 날짜: 2026-11-12
- 누가: Codex
- 관련: docs/spec.md R6·R11 / docs/coupang-automation.md

## 한 것
- 팀장이 검색결과 대신 실제 상품으로 연결하도록 요청해 파트너스 키 없이 사용할 수 있는 일반 상품 검색 모드를 추가했다.
- 기존 OpenAI 모델의 공식 웹 검색 API를 색인 전용·쿠팡 도메인으로 제한한다. 완료된 검색 출처와 인용 제목이 함께 있는 실제 상품 주소만 후보로 사용하고 기존 재료 대조를 거친다.
- 공개 JSON에는 일반 상품 주소와 실제 상품·옵션 ID만 저장한다. 제휴 수익은 없으며 가격·재고·사진을 수집하지 않는다. 실패·불일치면 기존 검색 연결을 유지한다.
- 기존 하루 한 번 자동화에 독립된 설정·호출 기록·보고서를 연결했다. 파트너스 자동화가 켜져 있으면 일반 검색은 실행하지 않는다.

## 바뀐 파일
- `web/scripts/web-products.ts` — 공식 웹 검색·출처 대조·일반 상품 주소 검증.
- `web/scripts/web-products.test.ts` — 출처 없는 주소 거절, 호출 제한 설정, 실패·미설정·CLI 미리보기·적용·재실행 6개 테스트.
- `web/scripts/auto-coupang.ts`, `web/scripts/coupang-automation.ts` — 일반 상품 모드와 기존 대조 공통 사용.
- `.github/workflows/pipeline.yml` — 일반 상품 단계·별도 캐시·보고서.
- `AGENTS.md`, `docs/coupang-automation.md` — 요청 범위·운영 방법·비용·검증 한계.

## 정한 것·남은 것
- 기존 실행당·시간당 검색 5회 제한과 재료 대조 기준을 재사용한다. OpenAI 검색·대조 비용이 기존 계정에 발생한다.
- 검색 색인 기반이므로 현재 판매 여부·옵션·재고는 구매자가 쿠팡에서 확인해야 한다. 기존 링크 재검사는 이번 범위에 없다.
- 로컬은 모의 응답으로 검증했다. 원격 설정 활성화·실제 검색·검사·배포 결과는 이어서 기록한다.
