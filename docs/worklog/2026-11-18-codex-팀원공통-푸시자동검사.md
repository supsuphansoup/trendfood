# 팀원 PC 공통 푸시 전 검사

- 날짜: 2026-11-18
- 누가: codex (AI 도구: Codex)
- 관련: 팀원도 GitHub에서 받아 같은 변경 통합 루틴을 사용하도록 요청

## 한 것
- `web/`에서 `npm ci`를 실행하면 저장소의 공통 pre-push 훅을 활성화한다. 이미 설치한 PC용 `npm run team:setup`도 제공한다. 새 패키지는 추가하지 않았다.
- origin/main 푸시 전에 최신 원격 커밋 포함 여부·깨끗한 작업 트리·검사 대상 HEAD를 확인한다. 코드·설정 변경은 네 검사를 실행하고, 공개 화면·콘텐츠 관련 경로는 콘텐츠 검사도 실행한다.
- 검사 후 로컬·원격 변경을 다시 확인한다. 누락된 팀원 변경·검사 실패·검사 중 변경은 푸시를 차단하고 기존 AGENTS 통합 절차를 안내한다. 자동 rebase·충돌 해결은 하지 않는다.
- 기존 훅·설정을 덮어쓰지 않으며 CI 설치를 건너뛴다. 팀원 안내를 README·AGENTS·CLAUDE에서 연결했다.

## 바뀐 파일
- `.gitattributes`, `.githooks/pre-push` — 훅의 LF 개행과 Git 진입점.
- `web/scripts/team-sync.ts`, `web/scripts/team-sync.test.ts` — 설치·푸시 검사와 임시 Git 저장소 통합 테스트 7개.
- `web/package.json` — prepare·team:setup 명령.
- `docs/team-workflow.md`, `README.md`, `AGENTS.md`, `CLAUDE.md` — 팀원 최초 설치·통합 절차·자동화 범위.
- 이 작업 기록.

- 실제 `npm ci`로 임시 클론에 훅을 설치하고 실제 `git push` 성공·검사 실패 시 원격 보존을 확인했다. 이 테스트도 전체 단위 테스트에 포함된다.
- 문서 경로 7개 존재 확인. `git diff --check` 통과. 화면 변경 없음.

## 정한 것·남은 것
- 원격 기준: `caa2c1f11b0be42541a2d75d3855aa60785ecf63`. 시작·검사 후 fetch에서 새 팀원 커밋 없음, 통합 충돌 없음. push 전 다시 fetch·rebase·확인한다.
- 팀원마다 최신 코드를 받은 후 `npm ci` 또는 `npm run team:setup`을 한 번 실행해야 한다. `git pull`만으로 로컬 Git 설정을 켤 수는 없다.
- 로컬 훅은 해제·우회 가능하다. GitHub 브랜치 보호 정책은 변경하지 않았다. 팀원 미푸시 작업과 의미상 충돌 검토는 자동화 범위 밖이다.
- 기존 훅과 충돌하면 보존하고 설치를 중단한다. 해당 PC에서 담당자가 기존 검사와 공통 훅을 함께 실행하도록 통합해야 한다.
