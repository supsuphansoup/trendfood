# PC 음식 카드의 너비와 사진 비율 조정

- 날짜 2026-11-26
- 작업자 Codex
- 관련 `docs/spec.md` R2, 기준 원격 `dbe834833efb2d5b8a28d34385a21f42de240745`

## 한 것

- 음식 목록 최대 내용 폭을 1600px에서 1360px로 조정했다.
- 1024px 이상에서 카드 폭에 비례해 사진 영역 높이를 정한다. 2열과 3열에서 3:2 영역 안에 원본 비율로 사진을 표시한다.
- 1920px 2열 화면에서 우베 라떼는 가로 약 524px에서 668px로 커졌다. 잔과 접시가 보이고 사진 옆 여백이 줄어든 것을 캡처로 확인했다.

## 바뀐 파일

- `web/src/components/home/home-feed.tsx` 목록·카테고리·필터의 최대 폭을 조정한다.
- `web/src/components/home/food-card.tsx` PC 사진 영역의 비율과 이미지 크기 힌트를 조정한다.
- `web/content-e2e/content.spec.ts` 390px·1280px·1920px에서 사진 영역의 비율을 검사한다.
- `docs/design.md` 목록 너비와 카드 사진 표시 기준을 기록한다.

## 검사 결과

- `git diff --check`, `npm run lint`, `npm run typecheck` 통과
- `npm run test:unit` 220개 통과
- `npm run test:e2e` 163개 통과, 모바일 전용 검사 1개는 PC에서 건너뜀
- `npm run test:content` 45개 통과, 와이드 PC 전용 검사 1개는 모바일에서 건너뜀
- `web/test-results/content/`의 `feed-wide-2-columns.png`, `feed-wide-3-columns.png`, `feed-mobile.png`를 확인했다.

## 정한 것

- 최대 폭과 사진 영역 비율은 PC의 실제 우베 라떼·두바이 쫀득쿠키 카드 구도를 기준으로 정했다.
- 작업 기준 이후 팀원 커밋 추가와 충돌 없음.
