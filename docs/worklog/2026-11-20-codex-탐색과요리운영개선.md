## 정한 것·남은 것

- 최근 발견은 ‘서비스 등록’ 기준이며 기존 날짜는 추정하지 않는다. 분량 계산은 명확한 숫자·단위만 바꾸고 복합 수량/조리 시간/상품 용량은 보존한다. 화면 켜두기는 선택한 경우만 요청한다.
- 사용자 답변: GA4 ID 아직 없음. 실제 방문 집계는 미연결이며 브라우저 도구는 `Computer Use native pipe is unavailable`(2회)로 계정 작업을 진행하지 못했다. Search Console·네이버 등록도 소유권 확인이 남아 있다. 연결 절차는 운영 문서에 적었다.
- 추가 유료 AI 수집/사진 생성은 실행하지 않았다. 하루 1회 예약·외부 API 한도는 유지한다. 무료 검사 전용 Actions 실행과 실제 배포 확인은 push 후 기록한다.
