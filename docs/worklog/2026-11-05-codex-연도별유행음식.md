# 2010~2025년 유행 음식 탐색

- 날짜: 2026-11-05
- 누가: Codex
- 관련: 사용자 직접 요청 / docs/spec.md R1·R2

## 한 것
- PC 카테고리의 찜한 음식 아래에 연도 슬라이더를 배치했다. 모바일은 카테고리 줄 아래에 표시한다.
- 동그란 손잡이로 2010~2025년을 1년씩 선택한다. 선택한 연도는 주소에 저장해 새로고침·뒤로가기에 대응한다.
- 사용자가 실제 자료 조사를 선택하여 16개 연도에 걸쳐 18개 유행 사례를 조사했다. 연도는 최초 출시 시점이나 순위가 아닌 해당 시기 유행 보도의 기준이다.
- 항목마다 짧은 설명·AI 요약 표시·기사 출처 링크를 붙였다. 게시된 레시피가 있는 두바이 초콜릿만 레시피 링크를 표시한다.
- 음식 카테고리·검색·찜으로 돌아가면 연도 선택이 해제되어 기존 탐색을 유지한다.

## 바뀐 파일
- `web/src/components/home/year-filter.tsx` — 접근성 이름을 가진 네이티브 연도 슬라이더와 선택·해제 버튼.
- `web/src/components/home/home-feed.tsx` — PC·모바일 배치, 연도 상태와 주소 동기화, 자료 목록 표시.
- `web/src/data/trend-history.ts` — 연도별 음식과 출처 URL. 근거 없는 통계·순위·조리법·이미지는 추가하지 않았다.
- `web/scripts/trend-history.test.ts` — 전체 연도 포함·중복·출처 필드 검사.
- `web/e2e/mvp.spec.ts` — 연도 범위·키보드 이동·주소 유지·출처·레시피·필터 복귀 검사.
- `docs/worklog/2026-11-05-codex-연도별유행음식.md` — 작업 기록.

## 정한 것·남은 것
- 사용자가 지정한 범위는 2010~2025년이며 실제 자료를 조사해 채우도록 답변받았다.
- 초기 손잡이는 2025년을 가리키며, 움직이거나 음식 보기 버튼을 누르면 연도 목록을 연다. 초기 메인 음식 피드는 유지한다.
- 여러 유행 중 대표 사례를 선정했다. 모든 연도에 하나 이상 있으며 일부 연도는 두 개다. 음식별 근거 링크는 데이터 파일과 화면에서 확인한다.
- 자료는 로컬 검토용이며 실제 배포 전 운영자 검토가 필요하다. 데이터베이스·자동 수집·새 상세 페이지·패키지 추가 없음.
- Git 조작·배포 사이트 변경 없이 로컬만 수정했다.
