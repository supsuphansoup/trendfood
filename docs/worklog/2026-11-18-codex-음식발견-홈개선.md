# 홈에서 유행 배경을 먼저 읽고 음식을 탐색하도록 개선

- 날짜: 2026-11-18
- 누가: Codex
- 관련: docs/spec.md R1·R2 / docs/plan.md 7단계 실데이터 화면

## 한 것
- 사용자가 UI 검토에서 제안한 음식 발견 중심 개선을 승인했다. PC 좌우 대표·2열 목록·세 번째 넓은 음식은 유지하고 대표 사진 높이와 반복 안내를 줄였다.
- 확인된 유행 배경을 설명보다 먼저 보여준다. 대표는 첫 문장 전체, 카드는 2줄 미리보기로 제공한다. 새 원고와 기존 음식 순환을 최신 유행으로 혼동하지 않게 대표 문구를 구분했다.
- AI·출처·추천 날짜는 키보드로도 열 수 있는 안내에 보존했다. 홈의 행동은 ‘음식 살펴보기’로 정리하고 레시피·재료 구매는 상세에서 이어지게 했다.
- ‘전체 음식 / 유행 기록 / 일상 레시피’를 추가했다. 모음별 개수·검색·찜·주소 보존·새로고침·뒤로가기를 확인했다. 완제품은 일상 레시피에서 제외하며 헤더의 찜은 다른 모음에서 저장한 음식도 보여준다.
- 생성 예시·실사 안내와 사진 원본 구도, 상세 구매 기능, 광고 위치는 보존했다. 사진 파일·음식 데이터·자동 수집·추가 AI 호출은 바꾸지 않았다.

## 바뀐 파일
- `web/src/components/home/home-feed.tsx` — 대표 영역 압축, 유행 배경·접이식 안내, 음식 모음·검색·주소 처리.
- `web/src/components/home/food-card.tsx` — 유행 배경 미리보기와 상세 링크로 카드 길이 단축.
- `web/src/app/theme.css` — 대표 음식명 PC 64px·모바일 36px 토큰.
- `web/e2e/mvp.spec.ts` — 탐색 후 상세 레시피·재료 구매로 이어지는 흐름 검증.
- `web/content-e2e/content.spec.ts` — 실제 콘텐츠의 모음·검색·찜·주소·키보드 안내·화면 높이 검증 추가.
- `docs/design.md`, `docs/spec.md` — 최신 화면 동작·시각 기준.
- 이 작업 기록.

## 팀원 변경 확인·통합
- 시작 기준과 push 전 확인한 `origin/main`: `8fd2aa6f63c8e3fe23c39e559445de03494a17e5`.
- `git fetch origin main`, `git log HEAD..origin/main`, `git diff --name-status HEAD...origin/main` 결과 새 main 변경 없음. 충돌 없음. 사용자 원래 작업 폴더의 미커밋 변경은 건드리지 않고 기존 깨끗한 worktree에서 작업했다.

## 정한 것·남은 것
- 색은 기존 흰색·먹색·레드와 원본 로고를 유지하고 정보 순서와 탐색 동작을 개선했다. 추가 패키지는 없다.
- 사진 자체의 품질과 실시간 최신 음식 확보는 이번 UI 변경으로 해결됐다고 주장하지 않는다. 검증된 기존 자료를 최신 트렌드로 꾸미지 않는다.
- 실제 배포 결과는 GitHub deploy와 운영 화면에서 확인한다.
