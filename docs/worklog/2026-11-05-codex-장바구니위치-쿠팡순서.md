# 장바구니 위치와 쿠팡 재료 이동 순서 수정

- 날짜: 2026-11-05
- 누가: Codex
- 관련: 사용자 직접 요청 / docs/spec.md R1·R6

## 한 것
- 떠 있던 통합 장바구니 버튼을 메인 상단 찜 옆으로 옮겼다.
- 상세 상단에도 찜 옆에 장바구니 버튼을 배치했다. 좁은 화면에서는 헤더가 줄바꿈되어 겹치지 않는다.
- 쿠팡 이동 클릭 시 진행 상태가 바뀌며 주소가 다음 재료로 바뀌는 문제를 막았다. 클릭한 주소를 먼저 새 창으로 열고 담음 상태를 갱신한다.
- 탭 1회에 주소 하나만 열며 기존 고지와 제휴 링크 속성을 유지한다.

## 바뀐 파일
- `web/src/components/shopping-cart.tsx` — 고정 위치 제거, 헤더용 버튼.
- `web/src/app/layout.tsx` — 전역 장바구니 배치 제거.
- `web/src/components/home/home-feed.tsx` — 찜 옆에 배치.
- `web/src/app/food/[slug]/page.tsx` — 상세 찜 옆에 배치.
- `web/src/components/detail/ingredient-cart.tsx` — 누른 주소를 먼저 열도록 변경.
- `web/e2e/mvp.spec.ts` — 헤더 위치와 연속 재료 이동 회귀 검사.
- `docs/worklog/2026-11-05-codex-장바구니위치-쿠팡순서.md` — 작업 기록.
