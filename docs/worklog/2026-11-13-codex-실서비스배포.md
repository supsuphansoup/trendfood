# 음식 이미지와 실사 우선 자동화의 실서비스 배포

- 날짜: 2026-11-13
- 누가: Codex
- 관련: docs/spec.md R1·R4·R14·R18 / docs/automation.md

## 한 것
- 사용자가 전체 액세스로 변경한 후 GitHub API와 원격 main 연결·쓰기 권한을 실제 확인했다. 운영 변수는 공개 JSON·자동 반영·사진 검색이 이미 활성화돼 있어 변경하지 않았다.
- 이전 작업에서 준비한 생성 이미지 26개, 검토를 유지한 실사 4개, 생성 표시와 출처 표시, 실사 우선 자동 검색을 함께 반영한다. 제외된 사진과 생성 원본 기록은 보존한다.
- 원격 main에 추가된 재료 상품 링크 3개를 보존하며 최신 main에 통합한다. `photos_only` 실행 설명도 생성 이미지의 실사 검색을 포함하도록 정리한다.

## 바뀐 파일
- 이전 사진 검색 확장·사진 품질 검토·음식 생성 이미지·실사 우선 작업에서 준비한 코드·사진·등록부·문서와 각 작업 기록.
- `.github/workflows/pipeline.yml` — 선택 검색처 환경변수 및 사진 전용 실행 설명.
- `docs/live-publish.md` — 전체 액세스 전환 이후 상태와 실제 배포 기록 경로.
- `docs/worklog/2026-11-13-codex-실서비스배포.md` — 이번 배포 검사와 결과.
- 개인 설정·비밀값·전달 ZIP·로컬 빌드 결과는 커밋하지 않는다.

- `git diff --check` 통과. `web/test-results/content/home-mobile.png`와 `home-desktop.png`를 열어 이미지·필터·카드 구조를 확인했다.
- Commons 실제 공식 검색 API에서 달고나 커피 후보 11개를 반환했다. Openverse는 이번 로컬 요청에서 실패 경고가 있어 검색 성공으로 보고하지 않는다. 운영의 검색·다운로드·AI 판별 결과는 배포 후 별도 확인한다.

## 정한 것·남은 것
- 호스팅·AI 모델·일일 검색량·예약 시각은 유지한다. Pexels 키는 현재 없으므로 Commons·Openverse를 사용한다.
- 배포 뒤 사진 전용 예약 작업을 한 번 실행하고, 실제 사진 교체 여부와 서비스 응답·파일 로딩을 확인한다.
