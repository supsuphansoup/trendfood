# 통합 장바구니 제거

- 날짜: 2026-11-16
- 누가: Codex
- 관련: docs/spec.md R3·R6 / docs/design.md 0장

## 한 것
- 홈·상세 헤더의 장바구니 아이콘과 상세의 통합 장바구니 담기 버튼을 제거했다.
- 사용하지 않는 통합 장바구니 컴포넌트·저장 코드와 개인정보 안내의 해당 항목을 제거했다.
- 상세의 재료 체크리스트·개별 쿠팡 구매 링크·목록 복사·공유와 찜 기능은 유지했다.
- 통합 장바구니의 기존 기능 테스트를 제거하고, 이전 저장 기록이 있어도 UI가 나타나지 않는지와 유지할 기능을 확인하는 테스트로 바꿨다.

- `web/content-e2e/content.spec.ts` — 실제 콘텐츠의 장바구니 UI 부재·구매 링크 유지 검증.
