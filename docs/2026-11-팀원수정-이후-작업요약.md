## 2. 무엇이 달라졌나

### 규칙·조사
- 팀 git 규칙: PR 을 만들지 않고, `git pull --rebase --autostash` 와 검사 통과 뒤 `main` 에 바로 push 한다.
- 수집은 **공식 API 만** 쓴다. 커뮤니티(DCinside 등) 크롤링은 약관상 금지라 보류했다.
- 네이버 키는 API HUB 에서만 새로 발급되므로 수집 코드를 HUB 방식(인증 헤더)으로 바꿨다.

### 방문자 화면
- `/privacy`(개인정보처리방침), `/terms`(이용약관) 본문과 `/about#contact` 삭제 요청 창구(운영자 메일 `trendfood2026@gmail.com`, 48시간 안 답장)를 넣었다. 법률 검토 전 초안이다.
- 상세 화면에 원본 YouTube 영상을 공식 플레이어(`youtube-nocookie.com`)로 넣고 "YouTube에서 보기" 링크를 단다. "관련 영상 n개" 표기는 지웠다.
- 사서 맛보기 내용이 없는 음식은 그 구역을 숨긴다.
- 올린 사진을 쓰는 음식은 상세 화면 사진 아래에 `사진: 출처 · 라이선스` 가 나온다.

### 관리자 화면 (`/admin` → 게시 관리)
- **기본 정보 고치기**: 이름, 카테고리, 태그, 조리 시간, 난이도, 분량, 순위 변동 문구.
- **사진·재료·조리법 고치기**: 사진 고르기·설명, 재료 추가/삭제/순서, 조리 단계·타이머, 사서 맛보기, 원본 영상 주소.
- **내림 사유 기록**: 숨기기/다시 보이기를 할 때마다 기록이 남고, 숨긴 음식에 사유와 메모(200자)를 저장한다. 관리자만 보고, 지울 수 없다.
- **사진 올리기**: 자기 기기의 사진을 긴 변 1600px·WebP·1MB 이하로 줄여 올린다. 출처 표시·라이선스·사용 확인 체크가 필수다. 주소를 넣어 남의 사진을 가져오는 기능은 없다.

### 자동 수집
- 자동 수집 후보에 남는 YouTube 유래 값(영상 제목 근거, 언급 수, 내부 점수)은 29일이 지나면 매일 수집 때 자동으로 비운다.
- 승인할 때 영상 개수를 음식에 복사하지 않고, AI 초안 지시문에 "YouTube 수치는 글에 쓰지 마세요" 를 넣었다.

### 사진 정책 (2026-11-11 팀장 결정)
- **AI 생성 사진은 쓰지 않는다.** 직접 촬영이 우선이고, 상업 이용 가능한 무료 사진은 보조다.
- 올린 사진은 [사이트에 반영] 때 내려받아 사이트에 포함한다. 하나라도 못 받으면 배포를 멈춘다.
