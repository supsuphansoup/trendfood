# Intent: 트렌드푸드 (TrendFood)

Author: supsuphansoup (팀장) · 정리: Claude Code. Status: approved (2026-11-05, 기획 v2.1 + 구조 결정 반영).
기준 문서는 `docs/intent.md` → `docs/spec.md` → `docs/plan.md` + `docs/design.md`. 이전 기획(v2.1 등)은 git 기록에만 남아 있으며 현재 기준이 아니다.

## Problem — 무엇을 해결/확인하고 싶은지
- SNS에서 뜨는 음식은 며칠 단위로 바뀌는데 "지금 뭐가 / 왜 뜨는지 / 어떻게 만드는지 / 어디서 사는지"를 한곳에서 볼 수 없다.
- 영상을 보고 재료를 하나씩 검색해 담기가 귀찮고, 그럴듯한 레시피도 실제로 실패할 수 있다. 해본 사람의 후기는 사용자 확보 후(Phase 2) 다룬다.
- 우리 팀은 이걸로 **돈이 거의 안 드는 구조에서 수익(쿠팡 파트너스 + 애드센스)이 나는지** 확인하고 싶다.

## Proposed outcome — 완성되면 무엇이 가능해지는지
- **"요즘 뜨는 음식, 여기서 제일 먼저"**: 방문자는 매일 바뀌는 급상승 음식 순위를 보고, 상세에서 근거·조리법·편의점 버전을 읽고, 집에 없는 재료만 쿠팡에서 **탭 한 번에 하나씩** 이어 담는다.
- 운영자는 PC 없이 매일 몇 분, 자동으로 모인 후보와 AI 초안을 **승인·수정만** 하면 사이트가 최신화된다.
- 운영비는 도메인 외 **월 0원**(무료 등급 서비스)으로 시작한다.

## Affected users and systems — 누가, 어떤 환경에서 쓰는지
- 방문자: 숏폼으로 음식 유행을 접하는 20~30대·자취생·1인 가구, **모바일 브라우저 위주**(PC도 지원). 가벼운 정보 소비에서 일부가 직접 요리·구매로 이어진다. 로그인 없음.
- 운영자: 팀원 1~3명(바이브코딩으로 개발), 숨겨진 `/admin` 에서 이메일 로그인.
- 외부 시스템: YouTube Data API, 네이버 데이터랩, OpenAI/Gemini API, 쿠팡 파트너스, Supabase, Cloudflare Pages, GitHub Actions.

## Constraints — 기술 스택, 꼭 지킬 조건
- 스택: Next.js 16(App Router, TS, **정적 내보내기**) + Tailwind v4 + shadcn/ui(Base UI) + Pretendard. 다른 UI 라이브러리 금지. 시각 기준 `docs/design.md`.
- 트렌드는 **공식 API만**(SNS·커뮤니티 크롤링, 자막 추출, 쿠팡 스크래핑 금지). AI 초안은 **운영자 승인 후 게시**, "AI 요약" 표시.
- 쿠팡: 사용자 탭 1회 = 상품 1개(자동·다중 오픈, 번들 전송, 최저가 비교 금지), 대가성 문구 상단 고정, 장바구니 주변 광고 금지.
- 무료 운영: Cloudflare Pages + Supabase Free + GitHub Actions(공개 저장소). 비밀값은 코드·채팅에 두지 않는다.

## Open questions — 아직 결정 못 한 것

2. 칩 높이 42px(시안) vs 터치 영역 44px.
3. 이번 달 이후 LLM을 Gemini **무료 등급**으로 쓸지 (입력이 공개 데이터뿐, 약관 확인 필요).
4. 대표 사진 출처 비중 — 결정(2026-11-11): AI 생성 사진은 쓰지 않고 자체 촬영 우선, 상업 이용 가능한 무료 사진은 보조.
5. 쿠팡 API 승인 전 **참고 가격을 보여줄지** 숨길지.
6. 사업자등록·통신판매업·부가통신사업 신고 필요 여부 (수익 발생 전 전문가 확인).
7. 익명 후기·평점(Phase 2)을 언제 시작할지 (사용자 수 기준).
