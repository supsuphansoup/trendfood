# 트렌드푸드 디자인 기준 (docs/design.md)

> 버전 1.0 · 2026-11-04 · 포토 피드형 확정안 기준
> 실제 화면(`web/`) + 이 문서가 시각 기준. 토큰 파일: `web/src/app/theme.css` (앱이 직접 불러오는 유일한 원본)
> 화면 구성·기능은 `docs/spec.md` 가 기준이고, 이 문서는 **어떻게 보이는지**를 고정한다. 시안과 다르면 최신 `docs/spec.md` 와 실제 화면의 결정을 따르며, 미결정 항목은 9장에 남긴다.

## 0. 원칙
1. **사진이 주인공.** 1위는 화면 가득, 2위부터는 한 줄에 하나씩 큰 사진. 글은 사진 옆(PC)·아래(모바일)에 둔다.
2. **색은 세 가지 역할만.** 진한 갈색 = 글자·주 버튼, 토마토 빨강 = 순위 숫자·장보기 CTA·링크·그래프, 베이지 = 칩·박스 배경. 다른 색을 새로 들이지 않는다 (예외: '담았어요' 초록, YouTube 재생 버튼 빨강).
3. **굵은 제목(900) + 차분한 본문(400).** 중간 굵기는 버튼·라벨(700), 칩(500)만.
4. **한 손 조작.** 누르는 것은 최소 44px, 재료 행·주 버튼은 56px.
5. **카테고리 탭.** PC(1024px 이상)는 왼쪽 200px 고정 탭(아이콘·이름·개수, 선택 시 `secondary` 바탕 + 빨강 아이콘), 모바일은 상단 가로 탭(선택 시 빨강 3px 밑줄). 정렬·태그 칩은 목록 위 고정 줄. 광고는 본문 흐름 안에만, 사이드바 광고 없음 (2026-11-04 변경).
6. 시안 HTML은 참고용이다. 코드는 shadcn 컴포넌트 + 이 토큰으로 새로 쓴다.

- **입력칸 테두리 변경:** 시안은 `#D9C9BD`였지만 흰 배경 대비 1.61:1로 WCAG 1.4.11(3:1)에 못 미쳐 `#9C8576`(3.48:1)로 바꿨다. `#D9C9BD`는 글자가 있어서 알아볼 수 있는 보조 버튼 테두리에만 쓴다.
- **대비 확인값 (WCAG AA 4.5:1 이상):** 갈색/흰 16.3 · 빨강/흰 6.3 · 흰/빨강 버튼 6.3 · 보조글자/흰 8.4 · 보조글자/옅은박스 7.8 · 보조글자/칩 7.3 · 빨강/칩 5.5 · 핵심배지 8.2 · 초록/흰 6.4 · 푸터글자/갈색 12.5.
- 빨강 `#B3301B`는 장보기 CTA와 순위에만 쓴다. 같은 화면에 빨강 버튼은 하나만 둔다.

## 2. 글꼴
- 실서비스: **Pretendard Variable** (dynamic subset, `next/font/local` 또는 CDN 고정 버전). 시안의 Noto Sans KR은 대체용으로만 본다.
- 모든 요소 `word-break: keep-all`, h1~h3 `text-wrap: balance` (`theme.css` base 층에 넣어 둠).
- 굵기: 900 큰 제목·순위·로고 / 700 버튼·라벨·강조 / 500 칩 / 400 본문.
- 숫자(순위, 배수, 가격)는 `tabular-nums`.

## 4. 간격·레이아웃
- **컨테이너:** 최대 폭 1200px, 좌우 여백 20px (`max-w-[1200px] mx-auto px-5`).
- **브레이크포인트:** 메인 카드 760px 이하에서 1열, 상세 860px 이하에서 모바일 배치(하단 고정 바). Tailwind로는 `md`(768px)를 기준으로 맞추고, 차이가 보이면 커스텀 값을 쓴다.
- **간격 단위 (px):** 4 · 6 · 8 · 10 · 12 · 14 · 16 · 18 · 24 · 28 · 32 · 36 · 44 · 56 · 64. 이 밖의 값은 쓰지 않는다.

## 6. 사진
- **비율:** 목록 카드 3:2 (`aspect-[3/2] object-cover`), 영상 16:9, 히어로는 영역을 꽉 채움(`object-cover`).
- **히어로 그라데이션 (글자 가독성):** 위에서 아래로 `scrim` 55~60% → 0%(28~30%) → 0%(38~40%) → 86~88%(바닥). 헤더와 제목이 모두 사진 위에 흰 글자로 올라간다.
- 사진이 늦게 뜰 때 바탕은 `secondary`. `next/image`에 `width`·`height` 또는 `fill` + `sizes`를 반드시 지정해 CLS를 막는다.
- 대체 텍스트는 "무엇이 어떻게 담겼는지" 한 문장 (예: "새우와 떡이 들어간 주황빛 로제 떡볶이"). 장식용 사진은 `alt=""`.
- AI 생성 사진은 쓰지 않는다(2026-11-11). 올린 사진은 상세 화면 사진 아래에 `사진: 출처 · 라이선스` 를 13px 로 표시한다.
- 지금 들어 있는 사진(`web/src/assets/demo/`)은 데모용. 실서비스 사진 조건은 `docs/spec.md` Design의 사진 절.

| :--- | :--- | :--- |

| 조리 단계 번호 | 직접 구성 | 44px 원, `primary` 바탕, 18px 900 |
| 타이머 버튼 | `Button` outline 작은형 | 높이 40px, 1.5px `primary` 테두리, `rounded-full` |

- AI 요약 아래에는 "AI가 공개 검색량과 영상 제목을 바탕으로 요약했고, 운영자가 검수했어요." 캡션.
- 시안 `detail.html`의 후기 스타일(`.rv`, `.field`)은 **Phase 2**라 지금은 만들지 않는다.

## 8. 접근성·동작
- 포커스: 3px `ring` 실선, 2px 띄움 (`:focus-visible`).
- 터치 영역 44×44px 이상. 아이콘만 있는 버튼은 `aria-label`.
- 상단 칩 줄은 `nav aria-label="정렬과 필터"`, 브레드크럼은 `nav aria-label="현재 위치"`.
- 진행 막대에 `aria-valuenow`/`aria-valuemax`, 그래프에 텍스트 설명.
- `prefers-reduced-motion`이면 전환 효과를 끈다. 기본 전환은 150ms 이하, 색·투명도만.
- 검증: Playwright 390px·1280px 스크린샷 + axe 위반 0건.

## 9. 아직 정하지 않은 것
- 다크 모드 (시안 없음. 정할 때까지 `.dark` 토큰을 만들지 않는다).
- 관리자 화면 시각 규칙 (shadcn 기본 + 이 색 토큰으로 시작).
- 아이콘 세트: **임시로 `lucide-react`** (shadcn 기본, `components.json`의 `iconLibrary: "lucide"`, 선 굵기 2px, 크기 20px 기본). 2026-11-05 팀·교수님 검토에서 확정하거나 바꾼다. 바꾸면 `components.json`과 import만 고치면 된다.
- tweakcn 편집기에서 `web/src/app/theme.css`를 불러와 미세 조정할지 (값을 바꾸면 이 문서 1장 표도 함께 고친다).
